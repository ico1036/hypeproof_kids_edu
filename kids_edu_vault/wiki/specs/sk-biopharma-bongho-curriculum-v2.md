# SK바이오팜 가족 AI 게임 창작 커리큘럼 v2 — 봉호 코어 적용본

## 0. 기준 정정

이 문서의 본체는 [[curriculum-core]]와 [[specs/skins/kids/skin-kids]]에 정리된 **봉호 태의 커리큘럼 코어**다.

[[hypeproof-studio]]는 커리큘럼의 주인이 아니라, 봉호 커리큘럼을 SK바이오팜 현장에서 안정적으로 실행하기 위한 구현 환경이다.

> **봉호 커리큘럼 = 교육 본체**  
> **SK바이오팜 조건 = 운영 제약**  
> **HypeProof Studio = 실행 OS**

## 1. 봉호 커리큘럼 원형

### 핵심 경험

```text
평소 = 지시받는 사람
        ↓
오늘은 내가 AI를 지시하는 사람
        ↓
내 것을 직접 만들어낸다
        ↓
증거를 손에 쥐고 돌아간다
```

SK바이오팜 버전에서도 이 순서를 절대 바꾸지 않는다.

### 5블록 코어

| 봉호 코어 | 목적 | SK바이오팜 4시간 적용 |
|---|---|---|
| 1. 도입 | “나도 할 수 있다” 가능성 심기 | AI 지휘관 선언 |
| 2. 탐색 | 자기 것에서 시작 | 내 캐릭터·세계·미션 고르기 |
| 3. 첫 시도 | 직접 해보기 | HypeProof Studio로 게임 V1 생성 |
| 4. 개선 | 첫 결과를 해부하고 다시 만들기 | 플레이 검증 → 질문 수정 → V2/V3 |
| 5. 공유 | 결과물 저장 + 서로 보여주기 | 발표, QR/URL, 성장 리포트 seed |

## 2. 이 수업의 핵심 장면

전체 4시간 중 핵심은 “게임을 만들었다”가 아니다.

핵심은 이 장면이다.

> 아이가 AI에게 말한다.  
> AI가 아이 생각과 다르게 만든다.  
> 아이가 “AI가 뭘 몰랐지?”를 발견한다.  
> 질문을 더 정확히 바꾼다.  
> 결과가 바뀐다.  
> 아이가 “내가 AI를 움직였다”고 느낀다.

이 장면이 없으면 HypeProof 수업이 아니다.

## 4. A/B반을 나누는 이유

1차 이유는 교육 철학이 아니라 **운영 제약**이다.

- SK가 이미 5·6학년 13명 / 3·4학년 10명 분반 의견을 요청했다.
- 총 23명을 한 번에 운영하면 코치 밀도와 완성률이 떨어진다.
- 초3과 초6은 읽기, 타이핑, 추상화, 게임 규칙 이해 수준 차이가 크다.

따라서 분반의 논리는 다음 순서다.

1. 운영 안정성
2. 완성률 보장
3. 학년별 난이도 최적화

### A반 — 초5·6, 13명

- 핵심: 규칙, 미션, 난이도, 검증
- 봉호 코어 중 강조: 첫 시도 → 개선
- 아이 역할: AI 지휘자, 플레이테스터, 수정 지시자
- 결과: playable game + 내가 고친 이유 발표

### B반 — 초3·4, 10명

- 핵심: 캐릭터, 세계관, 상상력, 소유감
- 봉호 코어 중 강조: 탐색 → 첫 시도 → 공유
- 아이 역할: 상상하는 사람, 선택하는 사람, 이름 붙이는 사람
- 결과: 내 캐릭터/세계가 담긴 간단한 게임 + QR/URL

## 5. 4시간 운영안 — 봉호 코어 기반

| 시간 | 봉호 코어 | 현장 활동 | 핵심 질문 | 산출물 |
|---|---|---|---|---|
| 0:00–0:20 | 도입 | AI 지휘관 선언 | “AI가 알아듣게 하려면 어떻게 말해야 할까?” | 지휘관 프레임 |
| 0:20–0:50 | 탐색 | 내 캐릭터·세계·미션 선택 | “내 게임은 누구의 어떤 이야기인가?” | 게임 씨앗 카드 |
| 0:50–1:30 | 탐색 심화 | 목표·규칙·금지요소 정리 | “AI가 아직 모르는 정보는 무엇인가?” | 게임 기획 카드 |
| 1:30–2:10 | 첫 시도 | Studio로 V1 생성 | “일단 만들어보면 뭐가 보일까?” | playable V1 |
| 2:10–2:50 | 개선 | 직접 플레이하고 다른 점 찾기 | “AI가 내 생각과 다르게 만든 부분은?” | 검증 메모 |
| 2:50–3:30 | 개선 | 질문 수정 → V2/V3 | “어떻게 말하면 더 내 생각에 가까워질까?” | 개선된 게임 |
| 3:30–4:00 | 공유 | 발표·QR/URL·성장 리포트 seed | “내가 만든 것과 고친 것은 무엇인가?” | 결과물 증거 |

## 6. HypeProof Studio 구현 원칙

Studio는 봉호 커리큘럼을 실행하기 위한 장치다. 기능은 봉호 코어를 강제해야 한다.

| 봉호 원칙 | Studio 구현 |
|---|---|
| 지시받는 사람 → AI를 지시하는 사람 | 첫 화면: “오늘은 네가 AI 지휘관” |
| 자기 것에서 시작 | 캐릭터·세계·미션 입력 없이는 생성 불가 |
| 첫 결과는 개선 재료 | V1 생성 후 바로 검증 화면으로 이동 |
| 올바른 질문이 결과를 바꾼다 | 수정 프롬프트 카드 제공 |
| 대신 해주지 않는다 | 코치 대시보드에 질문 유도 룰 표시 |
| 증거를 손에 쥔다 | URL/QR/발표 카드 자동 생성 |


## 6-1. Studio의 제품 은유 — 게임 만드는 게임

SK바이오팜 버전에서 [[hypeproof-studio]]는 “AI 코딩툴”이 아니라 커다란 게임기다. 아이는 그 안에서 게임을 만드는 게임을 한다.

- 게임기: HypeProof Studio
- 플레이어: 아이 + 부모
- 동료 NPC/엔진: AI
- 퀘스트: 내 캐릭터, 내 세계, 내 미션으로 게임 만들기
- 스테이지: 도입 → 탐색 → 첫 시도 → 개선 → 공유
- 보상: 뱃지, 레벨업, QR/URL, 발표 카드, 다음 버전 해금

이 은유를 쓰면 7 Assets의 관찰도 시험처럼 보이지 않고 게임적 성취처럼 보인다. 내부적으로는 7 Assets에 매핑하되, 아이에게는 지휘관 레벨/세계 설계자/플레이테스트 클리어/내 게임 출시처럼 보이게 한다.

## 7. Studio에 깔아야 할 스킬/룰/프롬프트

상세: [[hypeproof-studio-game-skillpack-v1]]

### Game Creation Skill

- 게임 목표 한 문장 만들기
- 캐릭터/세계/미션 정리
- V1 생성
- 직접 플레이 검증
- V2/V3 수정
- 발표 카드 생성
- QR/URL 생성

### Rule Pack

- 초등학생이 3분 안에 이해할 수 있어야 한다.
- 무섭거나 폭력적인 표현은 피한다.
- 목표와 조작법은 첫 화면에 보여준다.
- 결과물은 저장/공유 가능해야 한다.
- 코드/에러 메시지는 아이 화면에 직접 노출하지 않는다.

### Prompt Pack

- V1 생성 프롬프트
- 검증 질문 프롬프트
- V2/V3 수정 프롬프트
- 발표 카드 프롬프트
- 성장 리포트 seed 프롬프트

## 8. 7 AI Native Assets와의 관계

7 Assets는 별도 강의 주제가 아니다. 봉호 코어를 수행하는 과정에서 관찰되는 행동 신호다.

| Asset | 수업 중 드러나는 행동 |
|---|---|
| Intent Clarity | 내 게임의 목표를 말한다 |
| Context Design | 캐릭터·세계·규칙을 AI에게 알려준다 |
| Delegation Judgment | AI가 할 일과 내가 판단할 일을 구분한다 |
| Iteration Reflex | V1에서 멈추지 않고 다시 고친다 |
| Verification Reflex | 직접 플레이하고 다른 점을 찾는다 |
| Taste | 마음에 드는 것/아닌 것을 고른다 |
| Ownership | 내 게임을 내 말로 설명한다 |


## 8-1. 평가가 아니라 관찰 기록

7 Assets를 다루더라도 아이에게 “평가받는다”는 느낌을 주면 안 된다. 이 수업의 정서는 시험이 아니라 지휘관 경험, 창작 경험, 증거 수여다.

따라서 SK바이오팜 v2에서는 다음을 원칙으로 한다.

- 외부 표현: 평가/채점/점수 → 사용 금지
- 내부 표현: 관찰/흔적/성장 코멘트
- 아이 산출물: 내가 만든 것, 내가 고친 것, 다음에 만들 것
- 부모 리포트: 점수표가 아니라 짧은 서술형 관찰 기록

봉호님 확인 전까지 0/1/2 루브릭이나 정량 점수표는 사용하지 않는다.

## 9. 수업 후 증거물

봉호 코어의 마지막은 “증거를 손에 쥐고 돌아간다”이다. 따라서 아래는 선택이 아니라 필수다.

- 완성 게임 URL 또는 파일
- QR 코드
- 발표 카드
- 7 Assets 성장 리포트 seed
- 집에서 이어 만들 다음 프로젝트 제안

사원증/실물 카드는 현장 운영 가능하면 강하게 권장한다.

## 10. SK 회신용 핵심 문장

> 분반은 권장드립니다. 1차 이유는 운영 안정성과 완성률입니다. 현재 수요가 초3~초6 총 23명으로 넓고, SK 측에서도 5·6학년 13명 / 3·4학년 10명 분반 의견을 요청주셨습니다. 5·6학년은 규칙·미션·검증 중심으로, 3·4학년은 캐릭터·세계관·상상력 중심으로 운영하면 같은 4시간 안에서도 각 연령대에 맞게 “AI에게 지시하고, 결과를 보고, 질문을 고쳐, 내 결과물을 완성하는 경험”을 안정적으로 제공할 수 있습니다.
