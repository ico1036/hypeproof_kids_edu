# 치과 지식 슈퍼서치엔진 워크샵 v2

> 이 페이지는 artifact 인덱스다. 실제 내용은 같은 폴더의 `dental-supersearch-engine-workshop-v2.html` (HypeProof Studio · 치과 지식 슈퍼서치엔진 워크샵) 에 있다.
> HTML은 wiki 페이지로 등록하지 않고 여기서만 참조한다 — [[hypeproof-hyrox-framework-v1]] 과 같은 방식.

## 무엇인가

"원장님을 이겨라" 게임 장치와 [[seven-ai-native-assets-original|7 AI Native Assets]] 를 **검색스킬 제작 루프**로 엮은 HTML 제안서 겸 목업. 참가자가 치과 내부 지식을 자기 손으로 검색엔진에 밀어넣는 과정을 체험한다.
