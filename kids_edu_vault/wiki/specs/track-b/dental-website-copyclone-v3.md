# 보아치과 원장 강의 v3 — 봉호 코어로 다시 쓴 홈페이지 카피클론

## 0. v2가 틀린 점 (자기 정정)

v2는 "껍데기만 카피"라는 표면만 잡고, **HypeProof DNA를 하나도 안 박았다.** 빠진 것:
1. **봉호 코어** (AI 지휘관 서사 / 5블록 / "AI가 내 생각과 다르게 만든 걸 질문으로 고치는" 핵심 장면)
2. **오프닝 와우포인트** ("이런 걸 바로 할 수 있어요" 라이브 데모 전략)
3. **7에셋 행동신호 측정표** (Q&A 아님, 과정 신호로 관찰 — 정의가 이미 존재)
4. **실제 결과물 수준** (boaclinic.com 급: 네이버예약·카카오·SNS 연동 + 안정 배포처)

v3는 이 4개를 본체로 고정한다.

## 1. 한 줄 정의

> **평소 홈페이지를 외주에 맡기던 원장이, 오늘은 AI를 지시하는 사람이 되어 boaclinic.com 수준의 실제 운영 가능한 병원 홈페이지(네이버예약·카카오·SNS 연동)를 직접 만들고, 안정 배포된 URL과 "내가 고칠 수 있다"는 확신을 손에 쥐고 돌아가는 4시간.**

봉호 코어의 성인 번역:
```text
평소 = 홈페이지는 내가 못 건드리는 것 (외주 의존)
        ↓
오늘 = 내가 AI를 지시하는 사람
        ↓
내 병원 홈페이지를 직접 만들어낸다
        ↓
배포된 URL + 수정 능력을 손에 쥐고 돌아간다
```

## 2. 오프닝 와우포인트 (절대 빠지면 안 되는 장면)

수업 시작 첫 10분, 강사가 **라이브로 5분 만에 boaclinic급 사이트 골격을 띄운다.**
- "지금 보신 이거, 오늘 끝나면 **여러분이 직접** 만들어 갑니다. 외주 견적 받지 마세요."
- 효과: "나도 할 수 있다" 가능성 심기 → 봉호 코어 블록1(도입)과 동일 기능.

## 3. 핵심 장면 (이게 없으면 HypeProof 수업 아님)

> 원장이 AI에게 시킨다 → AI가 의도와 다르게 만든다 → "AI가 뭘 몰랐지?"를 발견한다 → 질문을 정확히 고친다 → 결과가 바뀐다 → "내가 AI를 움직였다"고 느낀다.

블록4(개선)의 심장. 카피클론에서는 "타깃과 다르게 나온 부분"이 바로 이 발견 트리거가 된다.

## 4. 봉호 5블록 × 4시간 운영안

| 시간 | 봉호 코어 | 현장 활동 | 핵심 질문 | 산출물 |
|---|---|---|---|---|
| 0:00–0:25 | **도입(와우포인트)** | 5분 라이브 데모 → "내가 AI 지휘관" 선언 | "AI가 알아듣게 하려면 어떻게 말해야 하나?" | 지휘관 프레임 |
| 0:25–1:00 | **탐색** | 정답지(타깃 사이트) 선택 + 구조 분해 + 내 병원 정보(진료과목·의료진·예약채널) 정리 | "내 병원은 누구에게 무엇을 보여줘야 하나?" | 섹션 분해표 + 병원 정보 카드 |
| 1:00–1:40 | **첫 시도** | 타깃 스크린샷 맥락주입 → V1 클론 생성 | "일단 만들어보면 뭐가 보일까?" | 클론 V1 |
| 1:40–2:30 | **개선(핵심 장면)** | 타깃과 다른 부분 발견 → 질문 고쳐 V2 / 콘텐츠 교체(도용금지) | "AI가 내 생각과 다르게 만든 부분은?" | V2 + 검증 메모 |
| 2:30–3:10 | **개선 심화** | 네이버예약·카카오·인스타·클릭투콜·지도 **연동** + 디테일 튜닝 | "환자가 실제로 예약까지 누를 수 있나?" | 운영 기능 붙은 V3 |
| 3:10–3:40 | **공유** | 안정 배포 → 공개 URL + 해커톤 베스트 선정 | "내가 만든 것과 고친 것은?" | 배포 URL + 베스트 |
| 3:40–4:00 | **공유/증거** | 의료광고 검증 + 집에서 이어갈 체크리스트 + 성장 리포트 seed | "게시 전 뭘 확인해야 하나?" | 검증 체크리스트 + 증거물 |

## 5. 결과물 수준 — boaclinic.com 벤치마크

"쌩 웹사이트"라도 최소 이 수준이어야 한다.

### 필수 섹션
Hero / 진료안내 / 의료진 소개 / 병원 둘러보기(시설) / 오시는 길·진료시간 / 예약 CTA

### 필수 연동 (운영 가능해야 함)
| 기능 | 연동 |
|---|---|
| 예약 | **네이버 예약 / 네이버 플레이스** 링크 |
| 상담 | **카카오톡 채널** 상담 버튼 |
| 전화 | 모바일 **클릭투콜**(tel:) |
| 위치 | 네이버/카카오 **지도 임베드** |
| SNS | 인스타그램·블로그 링크 |

### 안정 배포처 (결정)
- **기본 권장: Cloudflare Pages** — 무료, 트래픽 안정, 커스텀 도메인 무료 연결, HTTPS 자동.
- 대안: Vercel(동일 수준). 
- 도메인: 가비아 구매분 연결(현장은 무료 URL까지 보장, DNS 전파는 집에서 체크리스트로).

## 6. 7 AI Native Assets — 행동신호 관찰표 (Q&A 측정 금지)

> 원칙([[seven-ai-native-assets-original]]): 7에셋은 말로 설명하는지가 아니라 **실제 과정 신호**로 관찰한다. 평가/점수 표현은 외부 노출 금지, 내부는 관찰 기록.

| Asset | 이 수업에서 보는 행동 신호 |
|---|---|
| Intent Clarity | 첫 프롬프트에 병원 목적·타깃 환자·원하는 톤을 스스로 넣는가 |
| Context Design | 타깃 스크린샷 + 내 병원 정보(진료과목·예약채널)를 맥락으로 제공하는가 |
| Delegation Judgment | AI가 만들 것 vs 원장이 검수할 것(의료광고 표현)의 경계를 긋는가 |
| Iteration Reflex | V1에서 멈추지 않고 몇 번 돌아와 고치는가 |
| Verification Reflex | 예약버튼·링크·의료광고 문구를 **실제로 눌러보고** 검증하는가 |
| Taste | 정답지와 비교해 더 나은 기준으로 거부/수정하는가 |
| Ownership | "외주 줘야지"가 아니라 "내가 고칠 수 있다"로 회고하는가 |

→ Studio가 프롬프트 구조·수정 횟수·검증 클릭·회고 언어를 로그로 남겨 **서술형 성장 리포트** seed로 변환.

## 7. 가드레일

- **저작권**: 타깃은 구조·레이아웃 레퍼런스로만. 로고·사진·문구는 내 병원 자산/데모로 교체.
- **의료광고법**: "최고·유일·100%·치료 보장" 표현 금지. 게시 전 원장 최종 검수 필수.

## 8. 오픈 이슈

- 타깃 사이트 1개 확정 (boaclinic급, 재현 가능, 저작권 안전)
- 와우포인트 라이브 데모 대본 + 사전 빌드 백업본
- 네이버예약/카카오 연동의 현장 계정 준비(병목 가능)
- 해커톤 심사 기준표 (완성도/연동 작동/의료광고 검증/Taste)
- 3 vs 4시간 (연동까지 넣으면 4시간 권장)
