# SK바이오팜 프로그램 개요 2p v1

[[sk-biopharma-program-overview-v1-20260611]]에서 ingested 된 고객 공유용 A4 2페이지 문서.

## 한 줄 포지셔닝

> **코드는 AI가 씁니다. 아이는 생각을 씁니다.**

게임 만들기 수업처럼 보이지만, 실제로는 아이가 AI에게 생각을 설명하고 결과를 검증·수정해보는 가족 AI 창작 랩이다.

## 외부 노출 구조

1. Hero: 코드는 AI가 쓰고, 아이는 생각을 쓴다.
2. Program: 4시간 / 20가족·23명 / 2회차 / 노트북 지참.
3. Two Skills: Context Engineering + Feedback Loop.
4. Two Tracks: 초3·4와 초5·6의 운영 차이.
5. Parent Role: 부모는 질문하는 파트너.
6. 4-Hour Journey: 체험·제작 120분 + 완성 60분 + 발표 60분.
7. Takeaways: 완성 게임, QR/URL, 발표 카드, 성장 코멘트.
8. CTA: 사내 공지 채널에서 신청, 좌석 한정.

## 고객용으로 확정된 표현

- “코딩 문법”보다 “생각을 AI가 알아듣게 설명하는 힘”을 강조한다.
- 두 번째 힘은 **Feedback Loop**로 표현한다. v008의 Reflection 표기는 v009에서 환원됨.
- “와우포인트 6”은 내부 운영 전략으로 숨기고, 외부 문서에서는 `✦ 아이의 “와!”가 터지는 순간들` 정도로만 표시한다.
- “평가/점수/루브릭” 표현은 쓰지 않는다. 산출물은 “성장 코멘트”로 설명한다.

## 운영상 주의

> [!contradiction] 노트북 제공/지참 표현 충돌
> 이 2p 고객용 문서는 “팀당 노트북 1대 지참”이라고 말한다. 기존 [[sk-biopharma-curriculum-detail-v1]] 및 이전 설계안 일부에는 노트북 제공/렌탈/1팀 1노트북 문구가 섞여 있다. 외부 발송 전에는 **노트북 지참**으로 통일하거나, 실제 제공 정책을 재확인해야 한다.

## 산출물 정의

| 산출물 | 고객용 설명 |
|---|---|
| 완성 게임 | 브라우저에서 바로 실행 |
| QR / URL | 가족·친구와 공유 |
| 발표 카드 | 아이의 의도와 수정 과정 기록 |
| 성장 코멘트 | 코치 관찰 기반, 48시간 내 발송 |
