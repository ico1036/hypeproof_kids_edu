# SK바이오팜 일정/대상자 내부 설문 결과 — 2026-06-08

[[sk-biopharma]] 내부 설문 결과를 담은 이미지 소스. 발신자는 [[kim-jinhyuk]] 수석매니저이며, 참여 대상자 수·학년 분포·선호 일정·추가 요청사항을 공유했다.

## 핵심 내용

| 항목 | 내용 |
|---|---|
| 가족/구성원 | 20명 = 20가족 |
| 자녀 수 | 23명, 변경 가능 |
| 2자녀 희망 | 구성원 3명 |
| 선호 시기 | 2026년 7월 또는 8월 중 토요일 |
| 선호 응답 | 20명 중 17명 |
| 회차 | 2회차, 1회당 10가족 기준 |
| 요청 견적 기준 | 1st 13명, 2nd 10명 |

## 학년/분반 제안

| 클래스 | 학년 | 인원 | 해석 |
|---|---|---:|---|
| A | 5·6학년 | 13명 | 고학년 그룹 — 룰/미션/난이도/검증 중심 설계 적합 |
| B | 3·4학년 | 10명 | 저학년 그룹 — 캐릭터/스토리/상상력 중심 설계 적합 |

> [!key-insight] 분반 기준이 운영안으로 구체화됨
> 기존에는 학년/연령/수준별 분리를 검토하는 수준이었으나, 이 소스에서 5·6학년 13명과 3·4학년 10명이라는 실제 수요 기반 분반안이 등장했다.

## SK바이오팜 요청사항

1. 3·4학년 / 5·6학년 분반에 대한 HypeProof Lab 의견
2. 클래스 2회 진행 기준 견적
   - 1st: 13명
   - 2nd: 10명
3. 구성원에게 공유할 강의 커리큘럼 세부 자료
4. 7월 또는 8월 중 가능한 2회차 일정 확인
   - 예시: 7월 진행 시 7/11(토), 7/18(토)

## 운영상 의미

- 수요는 기존 15~20가족 가정보다 조금 더 구체화되어 **20가족 / 23자녀 / 2회차** 구조가 되었다.
- 기존 [[sk-biopharma-bitree-final-quotation-20260526]]는 10가족 1회차 기준이므로, 실제 요청은 2회차 총액 또는 13명/10명 가변 인원 기준 재견적이 필요하다.
- 커리큘럼 자료는 내부 공유용이므로, 단순 수업안보다 보호자가 이해할 수 있는 결과물·역량·일정·준비물 중심 문서가 필요하다.
