# Source — Weekly on HypeProof 2026-06-29

## 요약

- 보아치과 강의의 1차 고객 아웃풋은 치과 원장/실장이 직접 볼 수 있고 자랑할 수 있는 홈페이지 초안과 공개 URL이다.
- 강의의 진짜 차별점은 Claude Code 사용법이 아니라, HypeProof의 7 Assets/Studio/로그/경쟁/커뮤니티를 통해 AI 시대의 제작 기준을 체화시키는 것이다.
- 소나투스 자동차 AI 데모는 HypeProof 포지셔닝의 참고 사례로 쓰였다. 범용 LLM보다 도메인 언어, 워크플로우 통합, 테스트/결정론/브랜드 자산을 묶어야 방어 가능한 포지션이 생긴다는 교훈이다.

- HypeProof 고유성: 7 Assets 체화, Studio 로그, 경쟁형 레이스, 커뮤니티, KOL 채널 전략
- 전문직 채널 전략: 보아치과 원장을 치과 AI 강의 KOL로 세우고 이후 전문직 세일즈 채널로 확장
- 제품 레드 시그널: HypeProof Studio와 Claude Code 간 성능 격차를 리허설 전까지 테스트하고 줄여야 함
- 포지셔닝 원칙: 범용 AI 기능보다 도메인 맥락, 워크플로우 통합, 검증/스트레스 테스트, 브랜드 자산이 moat가 됨

## 핵심 정리

### 보아치과 강의 아웃풋

- 4시간 후 수강자는 자기 병원 자료로 만든 홈페이지 초안을 가져간다.
- 결과물은 로컬 화면이 아니라 공유 가능한 URL까지 가는 것이 이상적이다.
- V1과 최종본을 나란히 놓고, 어떤 맥락과 피드백이 결과를 바꿨는지 설명해야 한다.
- 설명 카드는 PRD라는 개발자 용어 대신 병원 강점, 환자층, 톤, 강조 진료, 첫 화면 메시지를 정리하는 오프라인/온라인 포맷으로 제공한다.
- 수강자는 발표와 투표를 통해 본인의 수정 이유를 말하고, 우수 사례는 라이선스/보상/다음 단계로 연결한다.

### 우리만 가능한 것

- 7 Assets를 단순 강의 슬라이드가 아니라 실제 제작 과정에서 행동 신호로 관찰한다.
- HypeProof Studio가 첫 결과, 수정 루프, 최종 결과, 회고 언어를 로그로 남겨 성장/성과 리포트 seed를 만든다.
- 강의는 도구 사용법이 아니라 디지털 서비스다. 수강자가 나중에 "이걸 계속 써야 한다"는 감각을 얻어야 한다.
- 보아치과 원장을 전문직 채널의 KOL로 만드는 것이 단기 강의 이상의 전략적 목적이다.
- 오프라인 모임, 경쟁, 커뮤니티, 제품 로그가 결합되어 범용 Claude Code 강의와 다른 경험이 된다.

## 모순·의문점

- Gemini 회의록/스크립트는 자동 생성본이므로 발화자·용어 오인식 가능성이 있다.
- 2026-06-27 포스터 v1은 외부 표현에서 내부 용어를 덜어냈지만, 이 회의록은 내부적으로 7 Assets/Studio/로그/경쟁이 차별점임을 다시 강하게 확인한다. 외부 카피와 내부 운영 설계를 구분해야 한다.
- HypeProof Studio가 리허설까지 충분히 동작하지 않으면 Claude Code/스킬 기반 fallback이 필요하다.
