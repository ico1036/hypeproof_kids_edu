# SK바이오팜 가족 AI 창작 워크숍 프로그램 개요 v1

- HTML: `.raw/articles/sk-biopharma-program-overview-v1-20260611.html`

- 기준: “설계안 v135”에서 고객 노출 검증 카피만 추출한 요약본 v010.

## 핵심 카피

> **코드는 AI가 씁니다. 아이는 생각을 씁니다.**

부모와 아이가 한 팀이 되어 AI에게 생각을 설명하고, 결과를 직접 확인하고, 더 정확한 말로 다시 고쳐 playable game 하나를 완성하는 4시간 가족 AI 창작 랩으로 포지셔닝한다.

## 고객 노출 프로그램 조건

| 항목 | 내용 |
|---|---|
| 대상 | [[sk-biopharma]] 임직원 가족, 초3~초6 자녀 |
| 규모 | 20가족 / 자녀 23명 |
| 팀 구성 | 자녀 1명 + 보호자 1명 = 1팀 |
| 회차 | 초3·4 10팀 / 초5·6 13팀, 2회차 |
| 일정 | 2026년 7~8월 토요일 |
| 준비물 | 팀당 노트북 1대 지참. 그 외 재료는 HypeProof Lab 준비 |
| 시간 | 4시간: 체험·제작 120분 + 완성 60분 + 발표 60분 |

> [!key-insight] 노트북 제공 문구 정정
> 이 고객용 v1에서는 “준비물 없음/노트북 제공”이 아니라 **팀당 노트북 1대 지참**으로 확정되어 있다. 기존 운영 문서의 “1팀 1노트북 제공/렌탈 필요” 표현은 외부 안내 전 재정합이 필요하다.

## 외부 노출용 두 가지 힘

이 문서는 7 Assets 전체를 노출하지 않고, 부모가 즉시 이해할 수 있는 두 가지 힘으로 번역한다.

1. **생각을 구체화하는 힘 (Context Engineering)**  
   “재밌는 게임”이 아니라 “고양이가 별을 모으는 3분짜리 점프 게임”처럼 상상을 캐릭터·세계·목표·규칙으로 정리해 AI가 이해할 수 있게 설명하는 힘.

2. **만들어보고 다시 고치는 힘 (Feedback Loop)**  
   첫 결과를 믿고 끝내지 않고 직접 플레이해 확인한 뒤, “AI가 무엇을 몰랐지?”를 찾아 더 정확한 말로 다시 요청하는 힘.

## 분반 메시지

- **초3·4 · 10팀**: “상상 → 선택 → 짧은 설명”  
  보기 카드와 문장완성형으로 시작해 캐릭터·장면 중심으로 만든다. 타이핑은 부모가 도와도 문장은 아이가 만든다.
- **초5·6 · 13팀**: “규칙 → 검증 → 개선”  
  점수·난이도 규칙을 직접 설계하고, 다른 팀과 게임을 바꿔 테스트하며 받은 피드백을 검토해 고친다.

## 부모 역할

> 부모는 대신 만드는 사람이 아니라, 질문하는 파트너입니다.

부모는 “왜 그렇게 정했어?”, “처음 하는 친구도 바로 이해할까?” 같은 질문으로 아이 생각을 끌어낸다. 정답을 알려주지 않는 것이 더 좋다는 메시지가 고객용 카피에 포함되어 있다.

## 산출물

- 완성 게임: 브라우저에서 바로 실행
- QR / URL: 가족·친구와 공유
- 발표 카드: 아이의 의도와 수정 과정 기록
- 성장 코멘트: 코치 관찰 기반, 48시간 내 발송

## 중요 차이점 / 기존 문서와 연결

- [[sk-biopharma-bongho-curriculum-v2]]의 봉호 코어를 고객용 2페이지 카피로 압축했다.
- 내부 전략인 “와우포인트 6”은 고객용 문서에서 직접 노출하지 않고 `✦` 마커로만 암시한다.
- [[seven-ai-native-assets-original]]/7 Assets는 외부에서 두 가지 힘으로 번역된다. 평가/점수/루브릭 표현은 계속 금지.
- HypeProof Studio는 외부에서 전면에 내세우지 않고, 아이의 생각과 가족 창작 경험을 주인공으로 둔다.
