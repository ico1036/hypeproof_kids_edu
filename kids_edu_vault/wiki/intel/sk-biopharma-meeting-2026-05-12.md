# SK바이오팜 미팅 후속 (5/12 → 5/14 정리)

## 제품 정체성

- **HypeProof Studio**: VS Code 기반 fork + 자체 chat panel
- SK바이오팜 1회차가 첫 데뷔 (브랜드 100% HypeProof)
- **HypeProof Proxy**: Anthropic API 중계 + 측정 데이터 자동 수집
- STT(음성 입력) v0.2부터 통합 예정 → 8-12세 타이핑 부담 해소

## 교육 IP — 16 Essence 프레임워크

학년대별 누적 적용 구조:

| 학년 | Essence 수 | 핵심 개념 |
|---|---|---|
| 초3~4 | 6개 | 감지·입력·소격 |
| 초5~6 | +5 = 11개 | AI 부리기 |
| 중1~2 | +5 = 16개 | 메타 사고 |

## 커리큘럼 플로우 — 4시간 5단계

| 단계 | 시간 | 이름 |
|---|---|---|
| 1 | 0:00~0:30 | 감지 |
| 2 | ~1:00 | 입력 |
| 3 | ~2:00 | 부리기 |
| 4 | ~3:00 | 검증 |
| 5 | ~4:00 | 사다리 |

**핵심 운영 원칙**: 부모-자녀 페어 모드 강제 (단독 참여 불가)

## 측정 체계

- 운영진은 수업 중 **트리거 질문**만 던짐 (직접 측정 X)
- AI가 사후 분석: 16 Essence 행동 매핑 + 페어 협업 패턴
- 운영진 검토 게이트 후 부모 리포트 (24-48h 내)
- 등급·순위 없음 → 본인 이전 회차와만 비교

## 운영 차별점

- 보조강사 = HypeProof Lab 운영진 직접 (CERN 물리 박사, AI/ML 엔지니어, 글로벌 마케터 등)
- 운영진 1인당 5~7 가족 코칭

## 일정

| 시점 | 내용 |
|---|---|
| 5/15~30 | HypeProof Studio v0.1 압축 빌드 |
| 5/28~30 | 운영진 자녀 dry-run (4시간) |
| 6/1주차 | Studio v0.1 release + 가족 안내 메일 |
| 6/2~3주차 | SK바이오팜 1회차 |
| 7월~ | Studio v0.2 (STT, web 모드) — 국립암센터 대비 |

**Plan B** (5/28 dry-run 미달 시): Cline + Proxy로 1회차 운영, Studio는 8월 정식 데뷔

## 운영 환경

- 가족 노트북 사전 설치 (One-line installer, 5분, Mac/Win)
- 백업 노트북 5대
- Manual-approve 모드 강제 (file write/exec 부모 승인 필수)
- 원본 대화 30일 자동 삭제, 익명 분석 결과 1년 보관
- 부모 동의서 7개 항목 (법무 검토 의뢰 예정)

## 비용 구조

- AI 사용료: 가족당 4시간 200K 토큰 한도 (~$5~10, HypeProof 부담)
- 회차당 인프라+AI: ~$20 (20가족 기준)
- Apple Developer 계정 $99/년
- Freelancer 검토: Track B chat panel UI ($5~8K)
