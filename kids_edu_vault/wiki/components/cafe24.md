# Cafe24

치과 홈페이지 외주/기존 제작 방식의 비교 대상으로 언급된 웹호스팅·홈페이지 운영 플랫폼.

## 세미나 역할

- 기존 방식: 도메인 구매 + 카페24/홈페이지 업체 서버 + 월 관리비.
- 제안 방식: 도메인만 구매하고 [[vercel]]/[[cloudflare]] 무료 배포를 활용해 서버비를 줄이며 수시 수정성을 높인다.
