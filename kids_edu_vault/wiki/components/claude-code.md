# Claude Code

치과 AI 홈페이지 만들기 세미나에서 샘플 홈페이지를 제작하는 AI 코딩 도구로 언급됨.

## 세미나 역할

- 참가자는 강사의 프롬프트와 화면을 따라가며 같은 샘플 홈페이지를 만든다.
- 교육 포인트는 도구 자체의 모든 기능 설명이 아니라, 초심자가 수정 요청을 말로 전달하고 결과물을 개선하는 경험이다.
