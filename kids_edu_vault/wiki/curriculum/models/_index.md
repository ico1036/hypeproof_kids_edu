# 교수학습 방법론 라이브러리

강의를 만들 때마다 다시 조사하지 않기 위한 자산. 각 카드는 **핵심 · 절차 · 근거 · 강점 · 약점 · 활용 조건 · 우리 라인 적용 · 흔한 오용** 8절 표준 포맷을 따른다.

**먼저 읽을 것**: [[evidence-standards]] — 근거를 다루는 원칙. 효과크기 서열화 금지 등.

## 라이브러리

| ID | 방법 | 계열 | 근거 | 강한 목표 | 약한 목표 | 선행지식 |
|---|---|---|---|---|---|---|
| [[m-explicit-instruction\|m-001]] | 명시적 수업 | explicit | **A** | 최초 습득, 규칙 전달 | 전이, 문제 발견 | 초심자 |
| [[m-guided-discovery\|m-002]] | 안내된 발견 | discovery | **A** | 판단 기준, 전이 | 속도, 절차 습득 | 초심자+안내 |
| [[m-cognitive-apprenticeship\|m-003]] | 인지적 도제 | apprenticeship | B | 암묵지 전수, 자율성 | 대규모, 표준화 | 초심~중급 |
| [[m-problem-based-learning\|m-004]] | 문제중심학습 | discovery | B | 기능·적용, 파지 | 지식의 양 | **중급 이상** |
| [[m-cooperative-learning\|m-005]] | 협동학습 | social | **A** | 또래 설명, 참여 유지 | 개별 증거 | 무관 |
| [[m-formative-feedback\|m-006]] | 형성평가·피드백 | assessment | **A** | 수행 개선, 자기조절 | 자아를 건드릴 때 | 무관 |
| [[m-poe\|m-007]] | **POE 예상·관찰·설명** | discovery | B | 선개념 진단, 오개념 노출, 진입 물증 | 지식 전달, 관찰 불가 대상 | 초심자 |
| [[m-project-based-learning\|m-008]] | **프로젝트 기반 학습 (PjBL)** | discovery | B | 산출물·외부 공개, 주체성 | 짧은 회차, 초심자 | **중급 이상** |

⚠️ **m-004(Problem-Based)와 m-008(Project-Based)은 다른 방법이다.** 국내에서 둘 다 "PBL"로 불려 근거 오적용이 잦다. Builder Portfolio 트랙은 **m-008**이다.

## 선택 가이드

### 1단계 — 학습 목표로 고른다

| 목표 | 1순위 | 보조 |
|---|---|---|
| 도구·절차를 쓸 수 있게 | m-001 명시적 | — |
| 안전·법·윤리 규칙 전달 | m-001 명시적 | — |
| **판단 기준을 스스로 갖게** | **m-002 안내된 발견** | m-006 피드백 |
| **선개념·오개념을 드러내야** | **m-007 POE** | m-002 |
| 진입 차시에서 강한 인상 | **m-007 POE** | — |
| 전문가의 사고를 전수 | m-003 인지적 도제 | m-002 |
| 실제 문제를 정의하고 해결 | m-004 Problem-Based | m-005 협동 |
| **산출물을 만들어 외부에 내보내기** | **m-008 PjBL** | m-005, m-006 |
| 자기 조절·중단 능력 | m-003(성찰) | m-006 |
| 관점의 상대성 체험 | m-005 협동 | m-002 |

### 2단계 — 선행지식으로 거른다

**이 단계를 건너뛰는 것이 교수 설계의 가장 흔한 실패다.**

```
선행지식 없음 ──▶ m-001 명시적 (m-004 금지)
      │
      ▼
기초 있음 ──────▶ m-002 안내된 발견 (안내 필수)
      │
      ▼
중급 이상 ──────▶ m-004 Problem-Based, m-008 PjBL, m-003 탐색 단계
```

- **초심자에게 비유도 발견·PBL을 쓰지 않는다.** 명시적 수업보다 나쁜 결과가 나온다 (Alfieri et al. 2011: d=−0.38)
- **숙련자에게 상세 안내를 계속 주지 않는다.** 전문성 역전 효과로 오히려 방해가 된다
- 즉 **안내의 양은 선행지식에 반비례해야 한다.** 이 한 문장이 라이브러리 전체의 요약이다

### 3단계 — 제약으로 확인한다

| 확인 | 걸리면 |
|---|---|
| 회차 시간이 충분한가 | m-004·m-008은 짧은 회차에 부적합 (m-008은 8주 이상) |
| 강사가 그 영역 실무자인가 | 아니면 m-003 모델링 불가 |
| 개별 증거가 필요한가 | m-005는 개별 책무성 장치 필수 |
| 재시도 기회가 있는가 | 없으면 m-006은 무의미 |
| 사적 정보를 다루는가 | m-005 집단 공유 금지 |
| 배치 제약 위반은 없는가 | → [[placement-rules]] |

## 이 라이브러리가 우리 설계에 건 수정

조사 과정에서 우리 자산에 반영된 것들. **방법론 카드는 참고 문헌이 아니라 설계를 바꾸는 입력이다.**

| 발견 | 반영 |
|---|---|
| 비유도 발견은 명시적 수업보다 나쁘다 | "안 준다"만으로는 부족. **탐색 공간 제한 + 설명 유도 + 피드백 통로**가 함께 있어야 함 → m-002 §7 |
| 모델링과 선취 금지는 충돌하지 않는다 | **강사 자기 과제에 대한 사고 표면화는 허용**, 학습자 과제의 답을 말하는 것은 금지 → m-003 §7 |
| 피드백 38%가 역효과, 원인은 자아 지향 | **헌법 B-1·B-2·B-3이 수행상으로도 유리**함이 독립 확인됨 → m-006 §7 |
| 개별 책무성 없는 협동은 무임승차 | 소집단 활동은 **개별 산출물 필드 필수** → m-005 §7 |
| PBL은 지식보다 기능에 유리 | 학부모에게 "AI 지식을 많이 배운다"고 말하지 않는다 → m-004 §7 |
| **국내 "문제 해결 학습 모형"은 PBL이 아니다** | 구조화된 4단계로 **안내된 발견에 매핑**. PBL 근거를 잘못 적용하지 않도록 명시 → [[kr-instructional-models-map]] |
| 과정중심평가 정의가 우리 Evidence와 거의 일치 | 학교·교사 대상 설명에서 **"과정중심평가의 실제 구현"** 프레이밍 사용 가능 |
| **Builder 트랙의 비평·수정 주체가 비어 있다** | PjBL 7요소 중 6번(비평·수정)에 대응하는 설계가 없다. 강사 금지 개입 탓에 비평 주체가 공백 → **동료·외부 사용자·AI 중 지정 필요** → m-008 §7 |
| **AI는 결정적이지 않아 POE의 전제가 하나 깨진다** | 예상을 **내용·변동성 두 층**으로 묻는다. 학습은 "내 예상이 틀렸다"가 아니라 **"하나의 답을 예상한다는 프레임이 틀렸다"** → m-007 §7 |

## 스키마 반영 완료

방법론 조사에서 도출되어 [[curriculum-schema]]에 등재된 필드. lint 7~9번으로 강제된다.

| 필드 | 요건 | 출처 |
|---|---|---|
| `guidance.space / .elicit / .feedback` | 발견형 활동은 3개 모두 필수. 하나라도 비면 방치 | m-002 |
| `individual_evidence` | 소집단 활동의 개별 산출물 | m-005 |
| `retry` | 재시도 기회. false면 형성평가가 아님 | m-006 |
