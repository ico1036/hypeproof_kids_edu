# 청소년 창업경진대회 — 심사 기준 해부

> ⛔ **문서 지위 (2026-08-17 D-1)**: 이 대회는 **커리큘럼의 목표가 아니다.** 국가가 창업 역량을 무엇으로 보는지에 대한 **벤치마크·1차 증거**로만 쓴다. 참가 요건(지도교사·동아리·진단 수행)에서 도출한 제약은 모두 무효다. → [[ruling-startup-ir-target-and-scope]]


국내에서 가장 크고 오래된(2015~) 청소년 창업 무대이며 **교육부 주최**다. 조사 당시에는 외부 피칭 대상 1순위 후보였으나 **D-1로 목표에서 제외**됐다. 지금 이 문서의 가치는 **배점표** — 국가가 창업 역량을 무엇으로 채점하는지에 대한 1차 증거다.

> ✅ **1차 출처.** 2025년 개최 계획 공문 PDF 원문에서 배점표·양식 목차를 직접 추출했다. 앞선 [[startup-minor-legal-boundary-kr]]과 달리 2차 출처 경유가 아니다.

## 대회 개요 (2025년 기준)

| | |
|---|---|
| 주최/주관 | **교육부**, 17개 시·도 교육청 / 한국청년기업가정신재단(KOEF) |
| 참가 자격 | 전국 초·중·고 및 학교 밖 청소년 **창업동아리** (2006년 이후 출생자) |
| 팀 구성 | **학생 2인 이상 + 지도교사 필수** |
| 신청 경로 | 온라인 창업체험교육 플랫폼 **YEEP**(yeep.go.kr) 등록 필수 |
| 일정 | 신청 5~6월 → 1차 예선(시·도) 7~8월 → 2차 예선(재단) 9월 → 결선 10월 |
| 결선 규모 | 50팀 (시·도별 최소 2팀 = 34팀 + 전국 예선 16팀) |
| 시상 | 대상 1(교육부장관상, 200만) / 최우수 5 / 우수 15 / 장려 29 |
| 심사위원 | 창업·창업교육 전문가, 창업교육 담당 교원, 진로교육 전문가 **5인 내외** |

## ★ 심사 배점표 — 여기가 핵심이다

심사 기준은 **아이템 품질이 아니라 「청소년 창업가정신 핵심역량」 4개 역량군**이다.

### 예선 (서면, 100점)

| 역량군 | 세부 항목 | 배점 | 소계 |
|---|---|---|---|
| **가치창출** | 기존 제품과 차별성 | 10 | **30** |
| | 사회적 가치 기여 정도 | 12 | |
| | 시장·고객 분석의 명확성 | 8 | |
| **도전** | 아이디어 발전 방법·계획의 적절성 | 8 | **30** |
| | **잠재된 문제·장애 요소 파악** | 10 | |
| | **발전 과정에서 다양한 시도를 했는가** | 12 | |
| **자기주도** | **자기주도적으로 발전시키려 노력했는가** | 12 | **20** |
| | 포기하지 않고 끝까지 노력했는가 | 8 | |
| **집단창의** | 구성원 특징 고려한 역할 분담 | 8 | **20** |
| | **구성원 간 의견 조율** | 12 | |

### 결선 (발표+부스, 100점)

| 역량군 | 세부 항목 | 배점 | 소계 |
|---|---|---|---|
| **가치창출** | 문제의식·아이디어의 혁신성 (10) / 성장 가능성 (5) / **사회적·경제적 가치 창출 효과 (15)** | | **30** |
| **도전** | **도전정신과 유연한 대응 (15)** / **긍정·부정 결과 예측과 대비 (10)** | | **25** |
| **집단창의** | **다양한 자원 활용 (15)** / 의견 조율 (5) / 협력 (5) | | **25** |
| **자기주도** | 자기주도적 발전 노력 (8) / **끝까지 노력 (12)** | | **20** |

**동점 처리**: 가치창출 → 도전 → 집단창의 → 자기주도 순.

### 이 배점이 말하는 것

**아이템 자체의 품질은 최대 30점이다.** 나머지 70점은 **과정·태도·협업**이다.

- "**다양한 시도를 하였는가**" 12점 — 결과가 아니라 **시도 횟수와 종류**
- "**장애 요소를 파악**" 10점 — 낙관이 아니라 **자기 반증**
- "**긍정·부정 결과 예측과 대비**" 10점(결선) — 같은 것의 결선판
- "**의견 조율**" 12점 — 팀 갈등을 **어떻게 다뤘는지**
- "**끝까지 노력**" 12점(결선) — 지속의 증거

→ **점수를 만드는 것은 산출물이 아니라 기록이다.** 무엇을 시도했고 무엇이 실패했고 어떻게 조율했는지가 남아 있지 않으면 70점을 증명할 방법이 없다.

## ⛔ 결정적 함의 — AI로 잘 쓰면 오히려 불리하다

우리 라인의 전제는 "AI의 도움을 받아 창업+IR을 한다"였다. 이 배점표는 그 전제에 **경고**를 보낸다.

| | AI가 대신할 수 있는가 | 배점 |
|---|---|---|
| 가치창출 (차별성·시장분석·사회적 가치 서술) | ✅ 상당 부분 | 30 |
| 도전 (시도의 이력, 장애 요소 파악) | ❌ **실제로 시도해야 존재한다** | 25~30 |
| 자기주도 (지속의 증거) | ❌ | 20 |
| 집단창의 (역할 분담·갈등 조율) | ❌ | 20~25 |

AI로 사업계획서를 매끄럽게 쓰면 **30점은 올라가지만 70점은 증거가 사라진다.** 심사위원 5인은 창업교육 담당 교원과 진로교육 전문가를 포함하므로, **말은 좋은데 과정이 없는 문서**를 판별하는 데 익숙할 가능성이 높다.

→ **커리큘럼 설계 원칙**: AI는 **문서 작성이 아니라 시도 횟수를 늘리는 데** 써야 한다. 같은 시간에 더 많은 가설을 검증하고, 그 이력을 남기는 방향. 이것은 [[measurement-axes]]의 **부하(Load) 축**과 정확히 같은 구조다 — "첫 답에 멈추지 않고 밀어붙이는 깊이. 길이가 아니라 단계."

**5축과의 대응**:

| 대회 역량군 | 우리 축 |
|---|---|
| 도전 — 다양한 시도 | **부하 (Load)** |
| 도전 — 장애 요소 파악 / 부정 결과 예측 | **검증 (Verify)** |
| 가치창출 — 문제 정의·시장 분석 | **입력 (Input)** |
| 집단창의 | (대응 축 없음 — 5축은 개인 단위) |
| 자기주도 — 지속 | 부분적으로 **거리 (Distance)** |

⚠️ **집단창의 45~50점에 대응하는 축이 우리에게 없다.** 5축은 개인 관찰용으로 설계됐다.
→ **D-3 판정**: 대회를 목표에서 제외했으므로 이 공백을 메우지 않는다. 8번째 Asset을 신설하지 않고 [[m-cooperative-learning]]의 개별 책무성 장치만 활동 설계에 넣는다. **증거는 개인에게 귀속시킨다.**

## 사업계획서 양식 목차 (제출 필수, 변경 불가)

```
동아리 현황 / 창업 아이템 개요(소개·차별성·주요 고객 및 판매 전략·이미지)
1. 문제인식
   1-1 창업 아이템의 개발 동기
   1-2 창업 아이템의 사회적 가치 창출
2. 실현가능성
   2-1 창업 아이템의 발전 과정 (+ 추진계획 표)
   2-2 시장 및 고객 분석
   2-3 개발 과정 중 예상되는 장애 요소
3. 성장전략
   3-1 개발을 위한 필요 자원
   3-2 판매 전략 / 홍보 전략
4. 팀 구성
   4-1 구성원 보유역량
   4-2 구성원 간의 갈등 해결 방법
   + 창업동아리 활동 자료 (도면·설계도·활동 과정)
```

> ★ **"구성원 간의 갈등 해결 방법"이 정식 항목이다.** 일반 IR 덱에는 없다. 이것은 투자 문서가 아니라 **교육 평가 문서**라는 뜻이다.

또한 **YEEP 창업가정신 핵심역량 진단 수행 일자**를 기재해야 한다(대표 학생 필수).
→ ✅ 진단도구를 확인했고 **헌법 5개 조항과 충돌**한다(백분위·T점수·상하위 25% 등급 명명·총합점수) → [[startup-yeep-benchmark-kr]]. **D-2로 대회를 목표에서 제외해 이 충돌은 소멸했다.**

## YEEP — 이미 무료로 제공되는 것

우리가 만들려던 것 상당수가 **국가 플랫폼에 이미 있다.**

| YEEP 기능 | 우리 라인과의 관계 |
|---|---|
| **온라인 사업설명회** — 실시간 영상으로 예비 투자자 대상 모의 IR | ⛔ **"IR 체험"은 이미 무료다** |
| **가상 크라우드펀딩** — 가상화폐 '잎'으로 자금 조달 체험 | ⛔ 중복 |
| **가상 마켓** — 상품 거래 체험 | ⛔ 중복 |
| 시장분석 — 이용자 설문 실시 | 중복 |
| 빅데이터 활용 시장탐색 | 중복 |
| 실시간 채팅 멘토링 / 전문가 피드백 | 중복 |
| GO! Startup — 가상 스타트업 홈페이지 운영 | 중복 |

→ **차별점을 "IR을 체험시킨다"에 두면 안 된다.** 전부 무료로 있다.

**남는 차별 후보**:
1. **가상이 아니라 실제** — YEEP의 IR은 가상 투자자·가상화폐다. ⚠️ 이후 정독에서 **"실제로 판단받는다"로 좁혀졌다** → [[startup-yeep-deep-read-kr]]
2. **시도 밀도** — AI로 검증 사이클을 몇 배로 돌리고 그 이력을 남기는 것
3. **개인 귀속 증거** — 국가 평가 체계에 개인 과정 증거 수집 장치가 없다는 것이 정독으로 확인됐다

## 채널 제약 — 학교 없이는 못 나간다

- **지도교사 필수**, 학생 **2인 이상 동아리**, YEEP 등록 필수
- 1차 예선은 **시·도 교육청이 자율 평가** — 지역 편차 존재
- **학교 밖 청소년 창업동아리도 참가 가능**하나 지도교사 요건은 동일

→ 사교육 단독 상품으로는 이 대회에 내보낼 수 없다.
→ ⛔ **D-1로 이 제약은 무효가 됐다.** 대회를 목표로 두지 않으므로 지도교사·동아리 요건이 우리 채널을 구속하지 않는다. 다만 **학교 채널로 갈 경우 이 대회가 다시 선택지가 된다**는 사실은 남는다 (그때는 진단도구 헌법 충돌을 다시 판정해야 한다).

## 남은 공백 — 다음 조사

- **YEEP 창업가정신 핵심역량 진단** 도구의 성격 — 문항·결과 형태·라벨링 여부 (헌법 B-3 충돌 검토)
- **KOEF 창업가정신 핵심역량 프레임워크** 원전 — UNESCO 3수준처럼 국내 준거로 차용 가능한지
- 시·도별 1차 예선 실제 평가 방식 편차
- 지도교사 요건의 실제 해석 — 외부 강사가 맡을 수 있는가
- 수상팀 사업계획서 실물 (YEEP에 탑재된다고 명시) — **실제 합격 수준을 보는 가장 빠른 길**
- 청소년비즈쿨 **운영기관 공모** 요건
