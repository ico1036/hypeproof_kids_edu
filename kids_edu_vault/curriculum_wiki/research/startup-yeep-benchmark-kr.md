# YEEP 벤치마크

교육부·한국청년기업가정신재단(KOEF)의 **온라인 창업체험교육 플랫폼 YEEP**은 창업·IR 라인의 **경쟁자이자 채널이자 하한선**이다.

> **이 조사의 목적**: 이미 무료로 있는 것을 모르고 만들면 중복이 된다. 무엇이 이미 있고 어디가 비어 있는지를 확정한다.
> 전수 목록·재수집 방법 → [[yeep-resource-manifest]]

## 규모 — 예상보다 훨씬 크다

| 자료실 | 게시물 | 첨부파일 |
|---|---|---|
| 창업체험교육 콘텐츠 | **53건** | **242개** |
| 수업·연구자료 | 30건 | 30개 |
| 기타자료 (시사 이슈 카드) | **120건** | — |

**전부 로그인 없이 다운로드된다.** 우선순위 47개 파일을 내려받아 2.5GB. 초·중·고 교안·워크북·PPT가 세트로 제공되며, 교구(카드덱)까지 PDF로 배포된다.

## ① 플랫폼 기능 — 우리가 만들려던 것이 이미 있다

| YEEP 기능 | 내용 |
|---|---|
| **온라인 사업설명회** | 실시간 영상으로 **예비 투자자 대상 모의 IR** |
| **가상 크라우드펀딩** | 가상화폐 '잎'으로 자금 조달 체험, 투자자 반응·피드백 확인 |
| **가상 마켓** | '잎'으로 상품 거래 |
| **시장분석** | 가상 스타트업별 이용자 설문 실시 |
| **빅데이터 활용 시장탐색** | 창업 사례·통계 탐색 |
| **GO! Startup** | 가상 스타트업 홈페이지 제작·운영, 사회공헌·채용·MOU 활동 |
| **실시간 채팅 멘토링** | 전문가 피드백 |
| **핵심역량 진단** | 아래 별도 항목 |

→ **"IR을 체험시킨다"는 차별점이 될 수 없다.** 전부 무료다.

## ② 콘텐츠 자산 — 완성도가 높다

### 주제별 콘텐츠 「창업가정신 학교에 가다」 시리즈

초·중·고 3종 세트(교안 + 워크북 + PPT)로 **13개 주제**가 배포돼 있다.

인공지능 · 데이터 · 네트워크 · IT · ESG · 지역문제해결 · 스마트시티 · 디지털 · 의료 · 관광 · 환경 · 패션&라이프스타일 · 문화콘텐츠 · 생활 · 창업가정신 · 교과연계(과학·사회)

**교과 연계판**도 별도로 있다 — 국어 / 정보 / 진로와 직업 / 진로융합.

### ★ 「실패 경험과 가치」가 있다

우리가 [[ruling-startup-ir-asset-alignment]]에서 "[[no-debug-philosophy]]는 이 라인에 안 온다, 대신 실패를 회수 가능하게 만든다"고 판정한 바로 그 자리에 **국가가 만든 패키지가 이미 있다.**

교사용 교안 + 학생용 워크북 + 카드뉴스 + 동영상 + e-book 5종 세트. **반드시 정독해야 한다.** 우리 판정이 이미 구현돼 있는지, 아니면 여기가 비어 있어서 우리 자리인지가 갈린다.

### 운영·정책 문서

- 창업가정신 함양 교육 **교수-학습 매뉴얼**(초/중/고) — ★ 교수학습법 직접 비교 대상
- 창업가정신 함양 교육 **프로그램 운영 매뉴얼**(초/중/고)
- **중점(거점)학교 운영 매뉴얼**(초/중/고)
- **학교급별 프로그램 모형 개발 보고서**
- **창업체험교육 백서**
- 2019 연구·선도학교 결과보고서(초/중/고), 교사연구회 결과보고서 13개 시·도

### 시사 이슈 콘텐츠 120건

"AI는 창작자의 새로운 파트너가 될 수 있을까", "폐차되는 열차가 키링으로?", "데이터센터가 우주로 간다?" 같은 **수업 소재 카드**가 상시 갱신된다.

→ 우리가 소재를 자체 생산할 필요가 없을 수 있다. **다만 이건 읽기 자료이지 활동이 아니다.**

## ③ ⛔ 핵심역량 진단도구 — 우리 헌법과 정면 충돌한다

원전: **「청소년 창업가정신 핵심역량 진단도구 개발」(2020.2, 교육부·KOEF, 278쪽)**
연구진: 한국직업능력개발원 손유미 / 연세대 장원섭 / 한국교육개발원 이강주 / 한국산업기술대 고혁진 / 진선여중 박소연

### 도구 사양

| | |
|---|---|
| 구조 | **4개 역량군 × 12개 핵심역량 × 48문항** |
| 형식 | **자기보고식 성향 평가**, 5단계 Likert |
| 소요 | 20분 (학교급별 15~25분) |
| 예비조사 | 2019.10, 전국 35개교 **3,017명** |
| 본조사 | 2019.12~2020.2, 초4~고3 **2,893명** |
| 신뢰도 | Cronbach α **0.97 이상** (전 역량군 0.9 이상) |
| 타당도 | 창업체험교육 이수 집단이 전 역량에서 유의하게 높음 / 성인 창업가·창업동아리 대학생 준거집단 비교 |

**근거의 질은 높다.** 국내에서 가장 잘 검증된 청소년 창업 역량 측정 도구다.

### 그런데 산출 방식이 문제다

> 규준표는 **백분위수와 T점수**로 "응답자의 **상대적 위치**"를 제공한다. 초·중·고 3개 집단별 규준.
> "상위 25%에 포함된 점수대는 **'높음'**, 하위 25%는 **'낮음'**, 중간은 **'보통'**의 **등급으로 명명하여 분류**"
> "**총합 점수를 산출**하여 ... 함양 정도를 확인 추적"

[[edu-constitution]]과의 충돌:

| 조항 | 충돌 |
|---|---|
| **A-1 진단 금지** | ⛔ 도구 이름 자체가 "진단도구" |
| **B-1 무순위** | ⛔ 백분위·T점수는 **정의상 서열**이다 |
| **B-2 합성 점수 금지** | ⛔ 총합 점수를 명시적으로 산출한다 |
| **B-3 진단 라벨 금지** | ⛔ '높음/보통/낮음' **등급 명명** |
| **B-5 관찰기록 ≠ 진단** | ⛔ 자기보고 응답을 역량 수준으로 해석 |

[[measurement-axes]]와도 충돌한다 — "**자기 보고를 단독 지표로 쓰지 않는다**"고 못박았는데 이 도구는 자기보고 단독이다. 근거는 [[ped-adolescent-cognitive-development-verification]](청소년 자기평가 정확도).

### ⚠️ 그런데 회피할 수 없다

[[startup-youth-competition-kr]] 참가 신청서에 **「YEEP 창업가정신 핵심역량 진단 수행 일자」 기재가 대표 학생 필수**다. **대회에 나가려면 이 진단을 받아야 한다.**

**판정 필요.** 쟁점은 하나다 — 헌법은 **우리가 하는 것**을 금지하는데, **참가 요건으로 외부 국가기관의 진단을 받는 것**까지 금지되는가.

세 갈래:
1. **분리** — 국가 진단은 대회 참가 절차일 뿐, 우리 커리큘럼은 결과를 사용·해석·언급하지 않는다. 학부모에게 사전 고지
2. **전면 회피** — 이 대회를 목표로 두지 않는다. 그러면 외부 피칭 대상을 새로 찾아야 한다
3. **역량군만 차용** — 진단 점수는 안 쓰되 **4역량군 × 12역량 어휘 체계**는 국내 준거로 차용 (UNESCO 3수준 차용과 같은 논리)

→ **3번이 유력하다.** 프레임워크의 어휘는 학교·기관 채널의 공통어이고, 점수·등급·규준만 버리면 헌법과 충돌하지 않는다. 단 **정식 판정 문서 필요.**

## 우리 자리는 어디인가 — 차별 후보 재검증

| 후보 | 성립하는가 |
|---|---|
| "IR 체험을 시킨다" | ❌ 이미 무료 (온라인 사업설명회·가상 크라우드펀딩) |
| "창업 커리큘럼을 준다" | ❌ 이미 무료 (13개 주제 × 초중고 3종 세트, 34차시 교안) |
| "카드·워크시트 자산" | ❌ 이미 무료 (교구 3종, 공통 활동지) |
| "실패를 다룬다" | ⚠️ 「실패 경험과 가치」 존재. **정독 후 판정** |
| "수업 소재" | ❌ 시사 이슈 카드 120건 상시 갱신 |
| **"가상이 아니라 실제"** | ✅ YEEP은 가상 투자자·가상화폐. 우리는 실제 고객·실제 심사역 |
| **"AI로 검증 시도 밀도를 높인다"** | ✅ 배점 70점이 걸린 지점. YEEP 콘텐츠에 AI 활용 설계 없음(인공지능은 *주제*로만 존재) |
| **"개인 귀속 증거"** | ✅ 동아리 단위 평가는 무임승차를 못 막는다. 로그 기반 개인 증거는 우리만 |

→ **살아남는 것은 셋뿐이고, 셋 다 [[seven-ai-native-assets-original]]에서 나온다.**

⚠️ 단 "AI 활용 설계 없음"은 **13개 주제 교안을 실제로 읽고 확인해야 한다.** 현재는 제목·목차 수준의 판단이다.

## 다음 — 정독 대상 (우선순위)

1. **「실패 경험과 가치」 교사용 교안 + 학생용 워크북** — 우리 판정과 직접 충돌/보완
2. **창업가정신 함양 교육 교수-학습 매뉴얼(고등학교)** — 국내 창업교육의 교수학습법 정본
3. **「창업가정신 학교에 가다 — 인공지능편」 교안** — AI를 어떻게 다루는지. 우리 차별점의 사활
4. **교구 3종 (가치·누구·무엇 카드)** — 카드덱 설계 비교
5. **「변화를 디자인하는 우리지역 미래 창업가 실험실」 34차시** — 장기 트랙 설계 참조
