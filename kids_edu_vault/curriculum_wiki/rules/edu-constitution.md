# 교육 라인 헌법

이 문서는 **참고 지침이 아니라 게이트**다. 컴파일러(L4)는 트랙·지도안을 출력하기 전에 이 조항들을 통과시켜야 하고, 통과하지 못한 산출물은 출력하지 않는다. 강사가 자기 강의를 만들 때도 같은 게이트를 거친다.

조항 변경은 승인 사안이다. 임의 수정 금지.

## A. 원 조항 (Jay 개요)

| # | 조항 | 위반이 만드는 것 |
|---|---|---|
| A-1 | **AI가 아이를 진단한다고 말하지 않는다.** 진단·해석은 외부 전문가의 일이다 | 무자격 심리 평가 |
| A-2 | **민간자격 등록 전에는 "자격증"이라 표기하지 않는다** — 수료증·이수증 | 자격기본법 리스크 |
| A-3 | **실제 관여 없이 전문가 이름만 광고에 쓰지 않는다** | 공정위 추천·보증 심사지침 위반 |
| A-4 | **부모의 불안을 팔지 않는다** — "뒤처진다"가 아니라 "자기 언어를 갖는다" | 상품 정체성 붕괴 |
| A-5 | **아동 개인정보는 법정대리인 동의 없이 수집·활용하지 않는다** | 개인정보보호법 위반 |

## B. 파생 조항

원 조항에서 직접 도출된다. 실무에서 위반이 실제로 일어나는 지점들이다.

### B-1. 가족 라인에 순위·등수·리더보드를 만들지 않는다
**근거: A-4.** 랭킹은 정의상 "뒤처진다"를 생산한다. 조직의 HYROX 기반 라이선스 체계에는 Record/Ranking 층이 있으나, 그것은 **성인·경기 라인 전용**이다(사업 볼트 `wiki/projects/`). 조직 표준이 틀린 것이 아니라 대상이 다르다.

파생: Evidence(Sediment)에 **아동 간 비교 뷰를 만들지 않는다.** 오직 자기 대비 시계열. 이것이 Family Annual Renewal의 판매 논리이기도 하다 — 파는 것은 순위가 아니라 "작년의 나 대비 변화"다.

### B-2. 측정 결과를 단일 합성 점수로 내지 않는다
**근거: A-1, A-4.** 합성 점수는 서열을 만들고, 서열은 비교를 만들고, 단일 숫자는 "진단"으로 읽힌다. 축별 프로파일만 제시한다. → [[measurement-axes]]

### B-3. 진단 라벨을 커리큘럼 자산에 넣지 않는다
**근거: A-1.** "완벽주의 아동에게는 상한을 낮춘다" 같은 **프로파일 기반 처방**은 우리가 진단 주체가 되었음을 뜻한다. 외부 전문가가 진단한다는 구조가 실질적으로 무너진다.

**대신 관찰된 행동에 반응한다.** "완벽주의 프로파일 → 상한 3회"가 아니라 **"5회를 다 채우려 애쓰는 모습이 보이면 상한을 낮춘다"**. 라벨이 아니라 눈앞의 행동이 트리거다. → [[ruling-profile-based-differentiation]]

### B-4. 수집 전에 동의가 선행한다
**근거: A-5.** Evidence 자동 수집은 법정대리인 동의 설계가 **먼저** 완료되어야 시작한다. 수집하고 나서 동의받지 않는다.

### B-5. Evidence가 담는 것은 "관찰 기록"이지 "진단"이 아니다
**근거: A-1.** 스키마 필드명부터 그렇게 간다. `diagnosis`, `profile`, `assessment` 같은 필드명을 쓰지 않는다. 해석은 외부 전문가가 별도 절차로 수행한다.

### B-6. 미성년 계정 약관을 커리큘럼에 내장한다
**근거: A-5.** 모델별 최소 연령·보호자 동의 요건은 활동 설계 시점에 반영한다. 사후 점검 사항이 아니다. 구체 요건은 조사로 확정한다(모델 정책은 자주 바뀌므로 날짜와 함께 기록). → [[edu-11-16-research-plan]]

## 위반 판정 체크리스트

컴파일러·리뷰어가 산출물마다 확인한다.

- [ ] 아동을 유형·프로파일로 분류하는 서술이 있는가 → B-3 위반
- [ ] 아동 간 비교·순위·상위 %가 있는가 → B-1 위반
- [ ] 단일 점수·종합 등급이 있는가 → B-2 위반
- [ ] "자격증"·"인증서" 표기가 있는가 → A-2 위반
- [ ] 전문가 실명이 실제 관여 근거 없이 등장하는가 → A-3 위반
- [ ] "뒤처진다"·"늦었다"·"또래보다" 프레임이 있는가 → A-4 위반
- [ ] 아동 산출물·로그 수집에 동의 절차가 선행하는가 → A-5/B-4
- [ ] 모델 사용이 연령 약관에 부합하는가 → B-6
