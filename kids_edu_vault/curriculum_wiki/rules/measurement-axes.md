# 측정 5축

## 정본

**이 문서의 5축이 커리큘럼 라인의 정본이다.**

### 조직 표준(HYROX 기반 rubric)과의 관계

조직에는 HYROX 모델을 따른 4축 측정 rubric이 있다 — 입력 품질 / 부하·반복 / 검증·조율 / 언러닝·전이. 사업 볼트(`wiki/projects/`)에 문서가 있으며, 성인·경기 라인에서 사용된다.

이 라인은 그 4축을 계승하되 두 가지를 달리한다.

| | 조직 표준 4축 | 커리큘럼 라인 5축 |
|---|---|---|
| 축 | 입력·부하·검증·전이 | **+ 거리(자기 조절)** |
| 산출 | 4축의 **합성 점수** | **축별 프로파일만.** 합성 금지 |

**두 차이의 성격이 다르다.**

- **5번째 축 추가는 조직 표준의 결손을 메우는 것**이다. 자기 조절은 가족 라인만의 문제가 아니며, 성인 대상 교육에서도 "AI에 과의존하지 않고 빠져나오는 능력"은 측정 대상이다. → **조직 표준에 확장을 제안해야 한다.** 아래 미결 참조
- **합성 점수 금지는 이 라인에 한정된다.** 경기 라인은 단일 점수가 없으면 랭킹이 성립하지 않는다. 조직 표준이 틀린 것이 아니라 대상이 다르다

### ⚠️ 미결 — 조직 표준 확장 제안

4축에 자기 조절 축이 없다는 지적은 커리큘럼 라인 밖에서도 유효하다. **사업 볼트 측에서 조직 표준 rubric 개정을 제안할 담당·경로가 정해지지 않았다.**

- 제안 내용: 4축 → 5축 확장, 성인 라인에서도 거리 축 측정
- 미해결 시: 커리큘럼 라인 단독으로 5축 유지 (현 상태)
- 성인 라인에서 이 축을 어떻게 관측할지는 미조사 (아동과 신호가 다름)

## 5축

| # | 축 | 무엇을 보는가 |
|---|---|---|
| 1 | **입력 (Input)** | 문제 정의, 맥락·제약 제공, 아는 것을 꺼내 쓰는 정도 |
| 2 | **부하 (Load)** | 첫 답에 멈추지 않고 밀어붙이는 깊이. **길이가 아니라 단계** |
| 3 | **검증 (Verify)** | 반증·교차 확인·실패 경로 설계 |
| 4 | **전이 (Transfer)** | 자기 규칙의 폐기와 갱신, 새 문제로의 이동 |
| 5 | **거리 (Distance)** ★ | **자기 조절 — 몰입을 알아채고 스스로 빠져나오는 능력** |

### 5번 축이 신설된 이유

Jay 개요의 첫 상품이 **AI Native Self Compass**다. 이름이 약속하는 것은 산출물이 아니라 **자기 이해**이고, 자기 조절은 자기 이해의 실행면이다. 기존 4축은 성과 축만 담고 있어 이 상품의 핵심 가치를 측정할 수 없다.

또한 부모가 실제로 지불하는 이유는 사용 능력이 아니라 **중단 능력**일 가능성이 높다. 이 가설은 조사로 검증한다. → [[edu-11-16-research-plan]]

## 측정 원칙

**단일 합성 점수를 만들지 않는다.** 축별 프로파일만 제시한다.
근거: 헌법 B-2. 합성 점수는 서열을, 서열은 비교를, 단일 숫자는 "진단"의 외양을 만든다.

**비교 대상은 오직 과거의 자신이다.** 아동 간 비교 뷰를 만들지 않는다. 근거: 헌법 B-1.

**측정값은 관찰 기록이지 진단이 아니다.** 필드명·표기에서 진단 어휘를 쓰지 않는다. 근거: 헌법 B-5.

## 거리 축 설계 제약 (조사 결과 반영, 2026-08-08)

청소년의 자기평가·메타인지 정확도는 성인보다 낮고, **특히 정서 상태 자기보고가 부정확**하다는 것이 복수 연구에서 지지된다. → [[ped-adolescent-cognitive-development-verification]]

따라서:

- **자기 보고를 거리 축의 단독 지표로 쓰지 않는다.** 행동·시간 기록 등 외부 관찰 가능한 지표와 병행한다
- **회고형 질문을 쓰지 않는다.** "지난주에 얼마나 몰입했나" 같은 기억 기반 질문은 부정확한 데이터를 만든다. 그때그때 기록하는 방식으로 설계한다
- 정서 관련 활동에서 아동의 자기보고에 의존한 판단을 하지 않는다

## 수준 — UNESCO 3수준 차용 (확정 2026-08-08)

**이해(Understand) → 적용(Apply) → 창조(Create)**

UNESCO AI 역량 프레임워크(학생용, 2024)의 진행 수준을 그대로 차용한다. → [[ped-ai-literacy-standards-kr-intl]]

### 왜 차용인가

- **등급이 아니라 진행 단계**다. 헌법 B-2(합성 점수·서열 금지)와 충돌하지 않는다
- 자체 등급 체계를 만들면 그 체계의 타당성을 우리가 방어해야 한다. **국제 프레임워크를 차용하면 방어 부담이 옮겨간다**
- 국내 성취기준에 우리 축(검증·거리)이 없는 상황에서, **국제 기준과의 정렬이 학교·기관 채널의 유일한 준거**가 된다

### 격자 — 5축 × 3수준

기록 단위는 **"이 축에서 어느 수준의 수행이 관찰되었는가"**다.

|---|---|---|---|
| 입력 | | | |
| 부하 | | | |
| 검증 | | | |
| 전이 | | | |
| 거리 | | | |

### 금지 사항

- 칸을 **점수화하지 않는다.** 채워진 칸 수를 세지 않는다
- 수준을 **아동에게 등급으로 제시하지 않는다.** 기록 어휘는 "관찰됨/미관찰"이며 "미달"이 아니다
- **트랙별로 도달 목표 수준을 다르게 둔다.** 예: Self Compass는 이해·적용, Builder Portfolio는 적용·창조. 같은 격자를 쓰되 목표가 다르다

### 미확정

- UNESCO 원문(PDF) 미독. 각 수준의 정의를 원문으로 확인해 우리 축에 맞게 진술해야 한다
- 5축 × 3수준이 15칸인데, 한 트랙에서 전부 관찰하려 하면 관찰 부하가 감당되지 않는다. **트랙별로 관찰 대상 칸을 제한**해야 한다
