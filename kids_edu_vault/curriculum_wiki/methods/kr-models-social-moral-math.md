# 사회과 · 도덕과 · 수학과 교수·학습 모형

> 근거 등급 **D**. → [[evidence-standards]] · 상위 문서: [[kr-instructional-models-map]]

**이 세 교과에서 우리가 가져올 것은 "가치·쟁점·의사결정"과 "개념 정의"와 "문제해결 절차"다.** 우리 라이브러리 6종이 전부 다루지 않는 영역이다.

## 사회과

### 개념학습 모형 — 3가지 변형

개념의 **속성과 사례, 그리고 사회적 상황**을 강조한다.

| 변형 | 접근 |
|---|---|
| **속성 모형** | 개념의 **결정적 속성**을 정의하고 사례·비사례로 확인 |
| **원형 모형** | 가장 **전형적인 사례(원형)**를 제시하고 그로부터 개념을 형성 |
| **상황 모형** | 개념이 쓰이는 **사회적 상황·맥락** 속에서 이해 |

**우리 라인 적용 — ⭐ 이식 가치 높음**

우리 라인은 정의가 어려운 개념을 다룬다: *환각, 편향, 프롬프트, 검증, 몰입, 소격.* 이 개념들을 강사가 정의해 주면 [[m-explicit-instruction]]이고, 헌법이 금지하는 선취에 가깝다.

**원형 모형이 특히 적합하다.** "환각이란 무엇인가"를 정의하는 대신 **가장 전형적인 환각 사례를 보여주고 학습자가 개념을 형성**하게 한다. `.raw` 1~2차시의 "본류/잡음 분류"가 사실상 원형 모형이다.

**속성 모형은 사례·비사례 대조**를 요구하는데, 이것이 검증 축 훈련과 직결된다.

→ 다음 작업에서 카드 작성 검토.

### 의사결정 모형 / 논쟁문제 수업 모형

**인지적 영역과 정의적 영역을 통합**하는 종합 모형으로 분류된다.

- **의사결정 모형** — 대안 탐색 → 결과 예측 → 가치 기준 적용 → 선택 → 정당화
- **논쟁문제 수업 모형** — 사회적으로 답이 갈리는 쟁점을 다룬다

**우리 라인 적용 — ⭐ AI 윤리 구간의 기성 틀**

AI 사용을 둘러싼 쟁점(어디까지 AI에 맡길 것인가, 과제에 AI를 쓰는 것은 부정행위인가, 아이의 대화 로그를 부모가 봐도 되는가)은 **정답이 없는 논쟁문제**다.

우리 헌법 A-4는 부모의 불안을 팔지 않는다고 규정하고, 이 모형은 **답을 주지 않고 쟁점을 다루는 검증된 형식**을 제공한다. 킥 합의서(부모 공동 서명) 활동이 사실상 의사결정 모형이다.

→ **부모 트랙과의 접합면에 유용.** 단 부모 트랙 내용은 파트너 IP → [[edu-11-16-parent-track-ip-boundary]]

### 탐구학습 모형 (사회과)

경험적 자료로 사회 현상이나 자기 주장을 검증하거나, 보편 법칙을 발견하려는 연구 방법이자 학습 모형.

→ [[m-guided-discovery]] 매핑.

## 도덕과

### 모형 목록

**콜버그 딜레마 토론 모형 · 가치명료화 모형 · 배려 모형 · 역할놀이 모형**

초등 도덕과에서는 **가치갈등 해결 · 합리적 의사결정 · 가치분석 · 콜버그식 도덕적 토론** 수업 모형이 교사용 지도서의 수업 절차와 연계되어 있다.

### 콜버그 딜레마 토론 모형

도덕적 딜레마(하인츠 딜레마 등)를 제시하고 **자기 판단을 정당화**하게 한다.

**중요한 한계**: 도덕성은 인지·정의·행동 측면으로 구성되는데, 콜버그 딜레마 토론이 발달시키는 것은 **인지적 측면(도덕적 추론 능력)에 한정**된다. 행동 변화를 보장하지 않는다.

**우리 라인 적용 — ⭕ 조건부**

- **강점**: "정당화를 요구한다"는 구조가 [[m-guided-discovery]]의 설명 유도(elicited explanation, d=0.36)와 같다
- **주의**: 콜버그 단계론은 Piaget 계열이며, 우리는 이미 Piaget 단계론을 트랙 분기 근거에서 기각했다 → [[ped-adolescent-cognitive-development-verification]]. **단계 판정을 하지 않고 형식만 차용**한다
- **헌법 저촉 위험**: 아동을 도덕 발달 단계로 분류하면 **헌법 B-3(진단 라벨 금지)** 위반이다. 단계 진단은 절대 하지 않는다

### 배려 모형 (Noddings 계열)

배려하는 관계 형성을 중심에 둔다. **모델링 · 대화 · 실천 · 확인**이 핵심 요소로 알려져 있다(미확인).

→ 부모–아동 관계를 다루는 구간에 관련 있으나 **파트너 IP 영역**이므로 우리가 개발하지 않는다.

### 가치명료화 모형

학습자가 자기 가치를 **스스로 선택·존중·행동**하도록 돕는다. 교사는 가치를 주입하지 않는다.

→ 헌법 A-4("자기 언어를 갖는다")와 정합. **Self Compass 트랙과 이름부터 맞닿아 있다.** 검토 후보.

## 수학과

### 폴리아 문제해결 4단계

**문제의 이해 → 계획 수립 → 계획 실행 → 반성·검토**

**우리 라인 적용 — ⭐ 4단계가 우리에게 유용**

마지막 **반성·검토(looking back)** 단계가 핵심이다. 대부분의 수업이 이 단계를 생략하는데, 이것이 [[m-formative-feedback]]의 재시도 요건, SRL의 자기성찰 단계, 우리 거리 축과 모두 연결된다.

AI 협업에 그대로 적용된다:
- 문제의 이해 → 무엇을 만들려는지 진술
- 계획 수립 → 프롬프트·접근 설계
- 계획 실행 → 생성·반복
- **반성·검토 → 결과가 원래 의도와 맞는가, 다시 한다면 무엇을 바꿀 것인가**

→ **활동 원자의 기본 뼈대 후보.** 단순하고 강사가 외우기 쉬워 라이선스 모델에 유리하다.

### 개념형성 학습 모형 / 발견학습 / 탐구학습

## 이 세 교과에서 가져올 것 — 요약

| 모형 | 우리에게 없던 것 | 우선순위 |
|---|---|---|
| **원형 모형** (사회과 개념학습) | 정의를 주지 않고 개념을 형성시키는 절차 | ⭐⭐ |
| **폴리아 4단계** (수학과) | 반성·검토가 내장된 단순한 뼈대 | ⭐⭐ |
| **논쟁문제·의사결정 모형** (사회과) | 답 없는 쟁점을 다루는 형식 | ⭐ |
| **가치명료화 모형** (도덕과) | 가치를 주입하지 않고 자기 가치를 세우게 하는 절차 | ⭐ |
| 콜버그 딜레마 토론 | 정당화 요구 형식 (단계 판정은 금지) | ⭕ |
