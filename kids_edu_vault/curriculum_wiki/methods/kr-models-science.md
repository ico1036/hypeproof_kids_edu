# 과학과 교수·학습 모형

> 근거 등급 **D** (개별 모형의 실증 연구는 존재하나 이 문서는 분류 체계 수준). → [[evidence-standards]]
> 상위 문서: [[kr-instructional-models-map]]

**우리 라인에 가장 이식성이 높은 교과다.** 과학과 모형은 "관찰 → 규칙성 발견 → 검증"을 다루는데, 우리가 AI 출력에 대해 하려는 것과 구조가 같다.

## 분류

| 유형 | 모형 |
|---|---|
| **공통** | 경험학습 · 발견학습 · 탐구학습 · 순환학습 · 개념변화학습 · STS |
| **특이** | 발생학습 · 창의적 문제해결 |
| **파생** | POE (순환학습의 변형) |

역사적 흐름: 초기에는 과학의 특성에 기반한 **탐구·발견 학습**이 주를 이루었고, 점차 학습자 특성을 반영한 **순환학습·개념변화학습**이 개발되었다.

## ★ POE (예상–관찰–설명) — 우리 1차시와 같은 구조

**Prediction → Observation → Explanation**

| 단계 | 내용 |
|---|---|
| **예상** | 관찰할 현상의 결과를 예상하고 **그 예상을 나름대로 정당화**한다 |
| **관찰** | 실제 관찰·실험으로 얻은 결과를 서술한다 |
| **설명** | **예상과 관찰 사이의 불일치를 해결**한다 |

세 단계가 순환적이라는 점에서 **순환학습의 변형**으로 분류된다.

### 왜 이 모형이 중요한가

**`.raw` 1차시 설계가 이미 POE다.**

| POE | `.raw` 1차시 「같은 질문, 스무 개의 대답」 |
|---|---|
| 예상 | 도입 15′ — "AI가 뭐라고 답할까?" **예측 문장 1개 작성** |
| 관찰 | 전개1 25′ — 사전 생성 카드 20장 통독, 놀란 것 3개 표시 |
| 설명 | 전개2·3 60′ — 분류·기준 협상·기준 재작성 |

우리가 독자적으로 설계한 것이 **국내 과학과에서 통용되는 검증된 형식**과 일치한다.

### 강점

- **수업 전 학습자의 선개념을 직접 확인**할 수 있어, 수업을 학습자 수준에 맞게 조정할 수 있다
- 예상과 관찰의 **불일치가 인지 갈등을 자동으로 생성**한다 → CASE의 인지 갈등 요소와 정합 ([[ped-cognitive-acceleration-case]])
- 설명 단계의 토의를 활용하면 개념 이해가 촉진된다

### 우리 라인 적용

**판정: 직접 이식. 우선순위 최상.**

AI 맥락에서 특히 강력한 이유: **AI 출력은 예측 불가능성이 본질**이다. "예상 → 실제 → 불일치 해명"이 AI를 다루는 경험 그 자체다.

- **예상 단계가 선개념 진단을 겸한다** — 아동이 AI를 무엇이라 생각하는지 드러난다. Evidence의 좋은 원료
- 전교조 조사에서 **25.9%가 "걱정되는 점이 없다"**고 답했다 → 예상 단계에서 이 무비판적 기대가 드러나고, 관찰 단계가 그것을 깨뜨린다 → [[ped-korea-elementary-ai-usage-2026]]
- 배치 제약 C-6(감탄 계열 + 검증 축 페어링)을 **한 모형 안에서 자동 충족**한다

→ **정식 방법론 카드로 승격 대상.** 다음 작업에서 `m-007 POE`로 작성.

## 개념변화 학습 모형 — 오개념 교정 전문

> 학습자가 **자신의 생각을 충분히 인식할 수 있도록 초기에 표현할 기회를 제공**하고, **인지적 갈등을 일으켜** 생각을 변화시킨 후, 과학 개념이 **이해 가능하고 그럴듯하며 활용 가능성이 많다**는 것을 보여준다.

(Posner et al.의 개념 변화 조건 — 불만족 · 이해 가능성 · 그럴듯함 · 유용성 — 계열)

### 우리 라인 적용

**판정: 이식 후보. 우선순위 높음.**

우리 대상의 AI 오개념이 데이터로 확인된다:
- "한 번 뽑은 결과가 그 모델의 실력"이라는 오해
- 초4~6의 **21.2%만 온라인 정보 출처를 확인**
- **25.9%가 "걱정되는 점 없음"**

**오개념 교정은 명시적으로 알려주는 것으로 안 된다.** 학습자가 자기 생각을 먼저 표현하고, 그것이 작동하지 않는 경험을 하고, 새 개념이 더 유용함을 확인해야 바뀐다. 이것은 [[m-explicit-instruction]]로 해결되지 않는 영역이다.

→ 다음 작업에서 카드 작성 검토.

## 나머지 모형

| 모형 | 단계·특징 | 우리 매핑 |
|---|---|---|
| **탐구학습** | 탐색·문제 파악 → 가설 설정 → 실험 설계 → 실험 → 가설 검증 → 적용·새 문제 발견 | [[m-guided-discovery]] |
| **발견학습** (Bruner 계열) | 구체적 사물·현상 관찰 → 규칙성 발견. **귀납적**. 구체 사례에서 일반 개념·법칙을 이끌어낼 때 효과적 | [[m-guided-discovery]] |
| **순환학습** (Karplus) | 탐색 → 개념 도입 → 개념 적용 (3단계). 학습자 특성 반영형 | [[m-guided-discovery]] |
| **경험학습** | 자유 탐색 중심. 저학년용 | ⭕ Lv1 도입부 후보 |
| **STS** | 과학–기술–사회 연계. 사회적 쟁점에서 출발 | ⭕ AI 윤리 구간 후보 |
| **발생학습** | 학습자의 선개념에서 출발해 새 개념을 생성 | 개념변화 계열 |
| **창의적 문제해결** | 확산·수렴 사고 결합 | 국어과 창의성 계발과 유사 |

> ⚠️ 단계 서술은 2차 출처(강의자료·교사 자료) 경유. 원 문헌 미대조.

## 이 교과에서 가져올 것 — 요약

1. **POE** — 최우선 이식. 이미 우리가 쓰고 있는 구조에 이름과 근거를 붙여준다
2. **개념변화 학습** — AI 오개념 교정. 명시적 수업으로는 안 되는 영역
3. **탐구학습 6단계** — 가설 설정·검증 구조. 우리 검증 축과 직결
4. **STS** — AI 윤리를 사회적 쟁점으로 다루는 틀
