## 1차시 | 같은 질문, 스무 개의 대답

| | |
|---|---|
| **주모형** | M1 표본-분류형 |
| **원리** | 09 백 번 뽑아보기 |
| **성취기준** | A-1. 동일 입력에 대한 복수 출력을 분류하고, 분류 기준을 자기 문장으로 진술할 수 있다 |
| **본질적 질문** | AI의 대답 하나는 무엇인가? |
| **평가 증거** | 분류표 1장 + 기준 문장 3개 |

### 흐름

| 단계 | 시간 | 교사 | 학습자 |
|---|---|---|---|
| 도입 | 15' | 질문 1개 제시. "AI가 뭐라고 답할까?" 예측만 시킴 | 예측 문장 1개 작성 (p.1) |
| 전개1 | 25' | 사전 생성 카드 20장 배부 (같은 질문의 20개 답) | 개별 통독. 놀란 것 3개 표시 |
| 전개2 | 35' | 분류 지시만. 기준은 주지 않음 | 3인 1조 분류. 기준 협상 |
| 전개3 | 25' | 조별 기준 게시 | 기준 비교. 자기 기준 재작성 |
| 정리 | 15' | "그럼 진짜 답은 뭐였을까" | 성찰 3문항 (p.4) |
| 확장 | 5' | 가정 연계 안내 | 부모에게 카드 3장 보여주기 |

### 핵심 발문
1. 20장 중에 '이건 확실히 틀렸다' 싶은 게 있어? 어떻게 알았어?
2. 너희 조 기준으로 나누면, 어느 칸이 제일 두꺼워?
3. 만약 21번째를 뽑으면 어느 칸에 들어갈 것 같아?

### 금지 개입 ⛔
- **정답 분류를 먼저 보여주지 않는다**
- "AI는 원래 그래" 같은 요약을 교사가 먼저 말하지 않는다
- 분류 기준을 제시하지 않는다. 기준 협상이 이 차시의 학습이다

### Lv1 변형 (90분)
카드 12장으로 축소. 기준 협상 대신 **미리 준비된 기준 4개 중 고르기**.

### 가정 연계
**당일 발송 물증 ★** — "오늘 아이가 발견한 것: 같은 질문에 AI가 20번 다르게 답했고, 그중 ○개는 사실이 아니었습니다"
이 메시지 한 통이 나머지 23차시를 판다.

### 준비물
표본 카드 20종 × 조별 세트 / 분류 매트 / 워크북 p.1–4

3. 이 판정, 다음 주에도 그대로일까?

### 금지 개입 ⛔
- 빈도와 정확도를 교사가 연결해주지 않는다. **반례 카드가 대신 말하게 한다**

### Lv1 변형
빈도 집계를 스티커로 시각화. 반례 카드는 2장.

### 가정 연계
부모에게 같은 질문을 직접 뽑아보게 하는 미션 카드 배부. **부모 인식이 가장 빨리 바뀌는 활동.**

## 5차시 | 두 모델을 마주 앉히다

| | |
|---|---|
| **주모형** | M1 |
| **원리** | 10 다중 모델 조율 |
| **성취기준** | A-2, B-1. 두 시스템의 답을 교차 비평시키고 어긋남을 정리할 수 있다 |
| **본질적 질문** | 둘이 다르게 말하면 누가 맞나? |
| **평가 증거** | 교차 비평 기록 (A→B 비평 / B→A 비평 / 내 중재 결론) |

### ⚠ 운영 필수 사항
Claude는 만 18세 이상, ChatGPT·Gemini는 만 13세 이상 + 보호자 동의다.
- **Lv1**: 강사 계정 2개를 스크린 공유. 아이는 계정 미접촉, **중재자 역할만**
- **Lv2**: 보호자 동의 하 부모 계정. 모델 A의 답을 **아이가 손으로 옮겨 적어** 모델 B에 전달 (필사가 정독을 강제)

### 흐름

| 단계 | 시간 | 교사 | 학습자 |
|---|---|---|---|
| 도입 | 10' | 놀람 일지 + 중재자 역할 부여 | |
| 전개1 | 25' | 동일 질문을 A·B에 투입, 스크린 게시 | 차이점 3개 표시 |
| 전개2 | 35' | A의 답을 B에게 비평시킴 (역방향도) | **필사 후 전달**. 비평 수집 |
| 전개3 | 30' | "중재자로서 결론을 내려라" | 중재 결론 작성 + 근거 |
| 정리 | 15' | 조별 결론 비교 | 내 결론 수정 |
| 확장 | 5' | | 가정: 부모에게 두 답 보여주기 |

### 핵심 발문
1. 둘이 어디서 갈렸어? 그 지점이 왜 어려운 지점일까?
2. B가 A를 비평한 게 맞는 비평이야?
3. 네가 중재자인데, 둘 다 틀렸을 가능성은?

### 금지 개입 ⛔
- **아이가 강사·부모 외 계정으로 직접 가입하게 하지 않는다** (약관 위반은 프로그램 존립 리스크)
- 어느 모델이 더 좋은지 교사가 말하지 않는다

| | |
|---|---|

### 흐름

| 단계 | 시간 | 교사 | 아동 | 부모 |
|---|---|---|---|---|
| 준비 | 15' | 규칙 선언 + 카드 배부 | 시연 준비 | **질문 카드 5장** 수령 |
| 시연 | 20' | 타이머 | 1–5차시 발견 시연 | 침묵 관찰 |
| 질문 | 20' | 평가어 감지 시 카드 회수 | 응답 | **질문만.** 조언·평가 금지 |
| 전환 | 20' | 역할 교환 안내 | **질문자** | 자기 AI 사용 경험 시연 |
| 합의 | 30' | 합의문 양식 | 공동 작성 | 공동 작성 |
| 정리 | 15' | 디브리핑 | "어떤 질문이 좋았나" | "조언하고 싶었던 순간" |

### 질문 카드 예시 (부모용)
- 그게 왜 놀라웠어?
- 어디서 막혔어?
- 다시 한다면 뭘 바꿀 거야?
- 그건 어떻게 알았어?
- 내가 뭘 도와주면 좋을까?

### 평가어 회수 규칙
"잘했네", "그건 좀", "그래서 뭐 할 건데" 등 평가·조언 발화 시 **질문 카드 1장 회수**. 5장을 다 잃으면 남은 시간 발언 불가.
→ 부모에게 가장 강한 학습이 일어나는 장치. 사전 고지 필수.

### 금지 개입 ⛔
- 교사가 부모를 대신 변호하지 않는다
- 아이의 시연을 교사가 보충 설명하지 않는다

## 7차시 | 첫 대답에 만족하지 않기

| | |
|---|---|
| **주모형** | M2 반박 사다리형 |
| **원리** | 03 부하 걸기 |
| **성취기준** | B-1. 받은 답에 대해 3단계 이상 반박을 이어갈 수 있다 |
| **본질적 질문** | 왜 첫 대답을 그냥 받아들이지? |
| **평가 증거** | 반박 사다리 3단 기록 (단계별 답 변화 포함) |

### 흐름

| 단계 | 시간 | 교사 | 학습자 |
|---|---|---|---|
| 도입 | 15' | 놀람 일지 + **"3번 되묻기" 규칙 선언** | |
| 전개1 | 20' | 1단(근거 요구) 시범 | 1단 실행 |
| 전개2 | 25' | 2단(반례 제시) 시범 | 2단 실행 |
| 전개3 | 25' | 3단(전제 공격) 시범 | 3단 실행 |
| 전개4 | 20' | "단계마다 답이 어떻게 변했나" | 변화 기술 |
| 정리 | 10' | | 성찰: "어느 단이 제일 어려웠나" |
| 확장 | 5' | | 가정: 부모 의견에 1단 적용 |

### 핵심 발문
1. AI가 물러섰어, 아니면 버텼어?
2. 3단까지 갔을 때 처음 답이 아직 남아 있어?
3. 네가 반박한 게 아니라 그냥 말을 바꾼 건 아닐까?

### 금지 개입 ⛔⛔
- **강사가 반박 문장을 대신 써주지 않는다**
- **글자 수를 언급하지 않는다.** 지표는 오직 단계 수
- 워크북에 글자 수 칸을 만들지 않는다

### ⚠ 오학습 감시
"길게 쓰면 좋은 것"으로 변질되는 것이 이 차시의 최대 위험이다. 조기 신호는 **입력란이 꽉 차는 것**. 발견 즉시 "몇 단까지 갔어?"로 재초점.

### Lv1 변형
3단 고정, 질은 묻지 않음. 반박 문장 시작어 카드 제공("근데 왜~", "만약 ~라면?", "그거 항상 그래?")

## 8차시 | 아는 걸 다 꺼내 쓰기

- 사용량이 많은 아이를 문제아로 취급하지 않는다
- 로그를 다른 아이와 비교하지 않는다

로그 회고 중 정서적 어려움(우울, 고립, 자해 관련 대화)이 드러나면 **즉시 활동을 중단하고 개별 대응**한다. 집단 앞에서 다루지 않는다. 강사 매뉴얼에 별도 프로토콜 수록 필수.

- 합의서에 벌칙 조항을 넣지 않는다

### 후속
1주 실행 → 24차시에서 디브리핑. **"스스로 멈춘 기록 3회"**가 수료 요건.

### 세일즈 주석
> "AI를 못 하게 막는 법이 아니라, 아이가 스스로 빠져나오는 법을 함께 설계합니다."

국내 청소년의 94.4%가 챗봇을 사용하고 정서적 의존이 정책 의제가 된 상황에서, 부모가 사는 것은 사용 능력이 아니라 **중단 능력**이다.

## 22차시 | 내 프롬프트를 만드는 프롬프트 *(선택 트랙)*

| | |
|---|---|
| **주모형** | M5 |
| **원리** | 13 추상의 사다리 |
| **성취기준** | A-4. 지시문을 생성하는 지시문을 설계하고 그 출력을 평가할 수 있다 |
| **본질적 질문** | 한 층 위에서 보면 뭐가 보이지? |
| **평가 증거** | 메타 프롬프트 1개 + 생성된 프롬프트 3개 + 품질 판정 |

### ⚠ 선택 트랙 운영
Lv1 제외. Lv2 상위군 대상. **필수화하면 못 하는 아이가 다수가 되어 좌절이 남는다.**
미참여 아동은 병행 세션(포트폴리오 정리)으로 운영.

### 흐름

| 단계 | 시간 | 교사 | 학습자 |
|---|---|---|---|
| 도입 | 15' | 3·9차시 자기 규칙 재소환 | 규칙 목록 확인 |
| 전개1 | 30' | "그 규칙들을 지시문으로 바꿔라" | 메타 프롬프트 초안 |
| 전개2 | 30' | 실행 → 프롬프트 3개 생성 | 생성물 수령 |
| 전개3 | 30' | **최하단 출력으로 내려가 평가** | 생성 프롬프트로 실제 작업 → 품질 판정 |
| 전개4 | 10' | "위층을 어떻게 고칠까" | 메타 프롬프트 수정 |
| 정리 | 5' | | 성찰 |

### 핵심 발문
1. 위층을 고쳤더니 아래층이 어떻게 바뀌었어?
2. 네 규칙 중에 지시문으로 안 바뀌는 게 있었어? 왜?
3. 이걸 계속 쓰면 뭐가 편해지고, 뭐가 위험해질까?

### 금지 개입 ⛔
- 메타 프롬프트 예시를 배포하지 않는다
- 미참여 아동을 열등하게 취급하지 않는다

## 23차시 | 3차시의 나를 반증하기

| | |
|---|---|
| **주모형** | M3 + M2 |
| **원리** | 14 언러닝 |
| **성취기준** | C-1, C-4. 자신이 세운 규칙을 스스로 반증하고 폐기할 수 있다 |
| **본질적 질문** | 내가 맞다고 믿었던 게 아직도 맞나? |
| **평가 증거** | 자기 규칙 폐기서 (3차시 규칙 3개 중 최소 1개 폐기 + 근거) |

### 흐름

| 단계 | 시간 | 교사 | 학습자 |
|---|---|---|---|
| 도입 | 15' | 놀람 일지 + **3차시 자기 규칙 3개 반환** | 재독 |
| 전개1 | 30' | "이 규칙이 틀렸다는 걸 증명해봐" (M3 적용) | 반증 시도 |
| 전개2 | 30' | 실증 테스트 | 규칙 위반 조건으로 실행 |
| 전개3 | 25' | 판정: 유지 / 수정 / 폐기 | 판정 + 근거 서술 |
| 전개4 | 15' | **"그때의 나는 왜 그렇게 믿었나"** | 자기 서사 기술 |
| 정리 | 5' | | 24차시 예고 |

### 핵심 발문
1. 그때는 뭘 몰라서 그 규칙을 만들었어?
2. 폐기하는 게 아까워? 왜 아깝지?
3. 지금 만드는 규칙도 나중에 폐기될까?

### 금지 개입 ⛔
- **규칙을 지켜온 것을 칭찬하지 않는다.** 이 차시는 폐기가 성취
- 교사가 어떤 규칙이 틀렸는지 지목하지 않는다

### 재등록 설계 주석
"1기에 배운 것을 뒤집는다"는 구조 자체가 **지속 수강의 논리**다. 새 모델이 나올 때마다 이 차시가 반복될 이유가 생긴다.

### 부모 트랙 연동
"내가 자랄 때 통했던 것이 지금 통하지 않는다" — 부모 트랙에서 **가장 저항이 크고 가장 값진 모듈**. 반드시 21차시(킥 합의) 이후에 배치한다.

## 24차시 | 데모데이 — 증거로 말하기

| | |
|---|---|
| **주모형** | M7 |
| **원리** | 07 공터 + 01 감탄하기 |
| **성취기준** | C-1~C-4 전항 |
| **본질적 질문** | 나는 무엇을 만들었고, 나는 어떤 사람인가? |
| **평가 증거** | 포트폴리오 + 수료 인증 |

### 흐름

| 단계 | 시간 | 내용 |
|---|---|---|
| 준비 | 20' | 포트폴리오 최종 점검 (실패 증거 2건 포함 여부 확인) |
| 발표 | 50' | 1인 5분: **성공 1건 + 실패 1건 + 폐기한 규칙 1건** |
| 질문 | 30' | 부모·외부인 질문만. 평가어 카드 회수 규칙 적용 |
| 킥 디브리핑 | 20' | 21차시 합의 1개월 결과 공유. **"스스로 멈춘 기록"** 확인 |
| 인증 | 15' | 수료 요건 6항 대조 → 배지 수여 |
| 정리 | 5' | 놀람 일지 24개 봉인 → 아이에게 전달 |

### 발표 필수 3요소
1. **성공 1건** — 외부 사용자가 실제로 쓴 것
2. **실패 1건** — 무엇이 어떻게 무너졌는지
3. **폐기한 규칙 1건** — 내가 틀렸다고 판정한 것

성공만 발표하는 것을 허용하지 않는다. 실패와 폐기가 없으면 **미수료**로 처리한다.

### 수료 요건 최종 대조
| # | 항목 | 확인 |
|---|---|---|
| 1 | 반박 사다리 5단 도달 3회 이상 | 9차시 기록 |
| 2 | 실패 설계서 1건 | 11차시 |
| 3 | **가족 외 외부 사용자 3명** | 18차시 |
| 4 | **킥 합의서 (부모 공동 서명)** | 21차시 |
| 5 | **스스로 멈춘 기록 3회 이상** | 10·19·21차시 |
| 6 | 포트폴리오 (실패 증거 2건 이상) | 24차시 |

5번이 이 프로그램에만 있는 인증 항목이다. **사용량이 아니라 중단 능력을 인증한다.**

### 금지 개입 ⛔
- 발표를 리허설로 다듬지 않는다. 연출된 발표는 부모가 알아본다
- 순위·시상을 하지 않는다. **비교와 성과 압박을 다루는 프로그램이 스스로 그것을 만들면 자기모순**
- 수료 요건 미달을 봐주지 않는다. 기준이 무너지면 인증의 가치가 사라진다

### 세일즈 주석
카톡으로 공유 가능한 링크 1개가 소개 전환의 핵심이다. 다만 **입시 활용을 먼저 말하지 않는다.** 부모가 알아서 발견하게 두면 신뢰는 유지되고 전환은 챙겨진다.
