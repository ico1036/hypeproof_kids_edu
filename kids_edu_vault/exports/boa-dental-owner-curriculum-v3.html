홈페이지 코드는 AI가 씁니다
원장님은 생각을 씁니다

원장님이 AI에게 우리 병원을 설명하고, 나온 결과를 직접 확인하고, 더 정확한 말로 고쳐 — 실제 운영 가능한 병원 홈페이지 하나를 완성하고, 끝난 뒤에도 직접 고칠 권한까지 가져가는 4시간 실습 강의입니다.

Program
4시간보기·만들기 中心 + 연동·다듬기 + 배포·점검 (쉬는 시간 포함)
치과 원장 · 실장비개발자 대상 · 코딩 지식 필요 없음
실제 운영 홈페이지네이버예약·카카오·지도 연동까지 작동하는 결과물
준비물: 노트북 1대그 외 데모 자료·계정 안내는 저희가 준비합니다
Two Skills
왜 이 두 가지 힘일까요 — 홈페이지 코드는 이미 AI가 씁니다. 원장님께 진짜 귀해지는 건 코딩 문법이 아니라, 우리 병원을 AI가 알아듣게 설명하는 힘(Context Engineering)과 나온 결과를 직접 확인하고 더 낫게 고치는 힘(Feedback Loop)입니다. 그래서 오늘은 이 둘을 강의로 듣는 대신 직접 겪으십니다.
①생각을 정확히 설명하는 힘 · Context Engineering

“좋은 홈페이지”가 아니라 “신뢰감 있는 톤으로, 임플란트·교정 중심, 첫 화면에 예약 버튼”이라고 말하는 힘. 우리 병원이 누구에게 무엇을 보여줄지를 AI가 이해할 수 있게 정리해 전달합니다.

②만들어보고 고쳐가는 힘 · Feedback Loop

첫 결과를 믿고 끝내지 않는 힘. 직접 눌러보고 “AI가 무엇을 몰랐지?”를 찾아, 더 정확한 말로 다시 요청해 내 의도에 맞춥니다. — 한 번에 맞히는 게 아니라, 고쳐 말해 내 것으로 만드는 능력.

실제 작동하는 연동

네이버 예약·플레이스 · 카카오톡 상담 · 전화 바로 걸기 · 지도 · 인스타·블로그 · 안정적 배포(+도메인)

잘 만든 치과 홈페이지 한 곳을 기준 삼아, 같은 수준으로 만듭니다 — 남의 사이트를 복제하는 게 아니라, 구조만 참고하고 내용은 우리 병원 자료로 채웁니다. 의료광고 표현은 게시 전 함께 점검합니다.

Takeaways
실제 홈페이지 URL그날 바로 공유
직접 고치는 능력자주 쓰는 수정 요청 카드
전환 체크리스트로고·사진·예약 링크 교체 절차
의료광고 점검표게시 전 자가 검수용

홈페이지는 결과물이고, 진짜 남는 건 “안 되면 고쳐 말해 내 것으로 만드는 힘”입니다.
오늘 원장님은 4시간 동안 그걸 직접 익히십니다.
