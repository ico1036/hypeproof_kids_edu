7 Assets 성장 증거

아이가 직접 정한 것, 고친 것, 확인한 것을 부모 언어로 보여준다.

3. 첫 시도V1 생성
4. 개선플레이테스트 후 수정
5. 공유출시·QR·다음 버전

7 Assets: 아이 넛지 ↔ 부모 리포트

1

Intent Clarity

목표를 세우는 힘

아이 넛지

“이 게임에서 친구가 뭘 하면 이겨요?”

🏁 퀘스트: 미션 한 문장
🎖️ 뱃지: 지휘관 선언 완료
부모 리포트
처음에는 “재밌는 게임”이라고 했지만, 이후 “고양이가 별을 모아 우주선을 고치는 게임”으로 목표를 구체화했습니다.

관찰 포인트: 목표 / 플레이어 / 성공 조건

2

Context Design

AI가 이해할 맥락을 설계하는 힘

아이 넛지

“AI가 아직 모르는 게 있어요. 주인공은 누구고 어디에 살아요?”

🗺️ 퀘스트: 세계관 카드
🏗️ 뱃지: 세계 설계자
부모 리포트
캐릭터 외형뿐 아니라 세계 배경과 장애물 조건까지 추가해 AI가 이해할 맥락을 넓혔습니다.

관찰 포인트: 캐릭터 / 배경 / 규칙 / 제약

3

Delegation Judgment

AI에게 맡길 것과 내가 판단할 것을 나누는 힘

아이 넛지

“AI가 만들게 할까요, 아니면 우리가 먼저 정해야 할까요?”

🤝 퀘스트: AI에게 맡길 일 고르기
🕹️ 뱃지: AI 동료 지휘 성공
부모 리포트
AI가 만든 화면을 그대로 받지 않고, 캐릭터 이름과 게임 목표는 본인이 결정했습니다.

관찰 포인트: 맡김 / 판단 / 부모 도움의 경계

4

Iteration Reflex

첫 결과에서 멈추지 않고 다시 고치는 힘

아이 넛지

“첫 번째 버전은 연습판이에요. 한 번 더 업그레이드해볼까요?”

🔁 퀘스트: V2 만들기
⬆️ 뱃지: 첫 수정 성공
부모 리포트
V1에서 목표가 잘 보이지 않는다고 판단하고, 미션 표시를 크게 바꾸는 수정을 요청했습니다.

관찰 포인트: 수정 횟수 / 수정 이유 / 구체성

5

Verification Reflex

직접 확인하는 힘

아이 넛지

“진짜 재밌는지 플레이테스트 해봅시다. 어디가 헷갈렸나요?”

🧪 퀘스트: 플레이테스트
🐞 뱃지: 버그 탐험가
부모 리포트
직접 플레이 후 조작법이 어렵다는 점을 발견했고, 버튼을 크게 바꾸자고 제안했습니다.

관찰 포인트: 실행 / 오류 발견 / 불편 설명

6

Taste

자기 기준으로 고르는 힘

아이 넛지

“이건 네 게임이에요. 어떤 느낌이 더 마음에 들어요?”

🎨 퀘스트: 내 스타일 적용
🎬 뱃지: 게임 디렉터
부모 리포트
귀여운 분위기를 원한다고 말하며 어두운 배경을 밝은 우주 배경으로 바꾸도록 요청했습니다.

관찰 포인트: 선택 기준 / 거절 이유 / 스타일

7

Ownership

내 프로젝트로 가져가는 힘

아이 넛지

“이 게임 이름을 붙이고, 친구에게 소개해볼까요?”

🚀 퀘스트: 내 게임 출시
👑 뱃지: 마스터 개발자
🔓 보상: 다음 버전 해금
부모 리포트
최종 발표에서 자신이 고친 부분과 다음 버전에 넣고 싶은 아이디어를 스스로 설명했습니다.

관찰 포인트: 발표 / 다음 계획 / “내가 만들었다” 언어

부모 리포트는 이렇게 짧게

캐릭터 이름, 게임 목표, 밝은 우주 배경

아이가 고친 것
